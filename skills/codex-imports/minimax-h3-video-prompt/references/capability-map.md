# MiniMax H3 能力路由

先识别用户真正需要控制的对象，再选择能力路径。以一个主能力承载任务，按需叠加辅助能力；不要按案例题材检索或拼接 Prompt。

## 目录

1. 商用内容生成
2. 原生多模态理解与生成
3. 全能精准编辑与修改
4. 路由规则

## 1. 商用内容生成

| 能力方向 | 用户信号 | Prompt 必须解决 |
|---|---|---|
| 品牌大片与影视内容 | 品牌片、TVC、预告、电影感、时尚 Campaign | 核心概念、主体关系、镜头节奏、品牌资产、整体视听气质和结尾落点 |
| 视觉创意与内容包装 | 动态海报、片头、文字特效、实拍融合、视觉实验 | 视觉媒介、版式层级、遮罩和转场触发、文字白名单、卡点和声音反馈 |
| AI 剧情内容创作 | 短剧、对白、关系冲突、角色表演、剧情钩子 | 人物身份、关系、情绪升级、动作和眼神、对白、正反打或连续调度、结尾钩子 |
| 产品与电商营销 | 产品广告、卖点展示、开箱、服装展示、带货 | 产品结构锁定、卖点顺序、功能演示、材质特写、使用情境、Hero Shot 和品牌文字 |
| 数字体验与游戏创意 | UI/UX、网页动效、游戏界面、实机视角、交互演示 | 交互顺序、第一/第三人称逻辑、UI 屏幕锁定、文字数值、操作反馈和状态变化 |
| 硬件、实体工业、具身智能 | 机械设备、机器人、制造流程、工业演示、空间操作 | 几何结构、部件数量、关节和运动范围、操作顺序、接触与受力、环境反馈、安全边界和完成状态 |
| 动画与风格化影像 | 二维动画、三维卡通、定格、剪纸、像素、国风、风格实验 | 唯一视觉体系、线条、材质、帧感、动作规律、角色一致性和禁止混入的其他媒介 |

题材只决定强调项，不决定固定模板。用户的具体目标始终高于表格中的常见写法。

## 2. 原生多模态理解与生成

### 多素材联合参考

用于多张图片、多段视频和音频共同控制成片。先建立素材职责表，再写主次优先级和冲突处理。Prompt 必须能回答“每份素材负责什么、什么必须保持、什么可以变化”。

### 角色、动作与镜头参考

将控制层拆开：

- 人物图负责身份、脸、发型、体型或服装。
- 产品图负责结构、标签、材质和品牌。
- 参考视频负责动作、机位、运镜、构图、切镜或节奏。
- 风格图只负责光线、色彩、材质和媒介，不覆盖人物身份。

用户要求“保持原视频拍法”时，把动作、机位、运镜、转场和卡点逐层锁定，不能只写一句“参考视频1”。

### 音色克隆与迁移

明确音频负责音色、对白、音乐还是节拍。声音迁移必须同时写清说话人、准确台词、情绪、时点、口型同步和需要保留或删除的原声层。

## 3. 全能精准编辑与修改

### 角色与物体编辑

列出被编辑对象的最终状态，保持未点名人物、物体、动作、遮挡、光影和镜头不变。换入对象必须适配原有握持、接触、运动模糊、反射和阴影。

### 场景与视觉效果编辑

编辑背景、时间、天气、光线或风格时，同步调整主体受光、环境反射、阴影、景深和遮挡。局部风格化要明确作用范围，避免整幅画面被错误重绘。

### 声音、台词与音色修改

写清原声中哪些层保留、替换或删除。更换台词时同步修改口型、停顿、呼吸、表情和动作强度；更换音色时保持说话人身份和空间声学合理。

### 高精度指令遵循

把多项修改拆成原子清单，每项包含对象、位置、原状态约束和最终状态。检查：

- 是否遗漏任何一项修改。
- 是否意外改变未点名内容。
- 多项修改之间是否互相冲突。
- 变化是否同步影响光影、遮挡、声音和物理接触。
- 文字、颜色、数量、左右位置和先后顺序是否准确。

单点修改使用短指令；多点修改使用清晰列表。不要把精准编辑扩写成一次新的故事创作。

## 4. 路由规则

按以下顺序判断：

1. 用户是否要求修改已有视频？是则主路由为精准编辑。
2. 用户是否要求保留参考视频的动作、镜头或节奏？是则主路由为多模态参考，并建立逐层保留策略。
3. 用户是否要求精确人物、产品、风格或声音？是则为对应素材分配职责。
4. 用户是否提供首帧或尾帧并要求固定起止画面？是则使用首尾帧模式。
5. 以上都不是时，使用文生视频并按商用内容方向组织镜头。

同一任务可以叠加多个能力，例如“产品广告 + 人物图 + 动作视频 + 音频卡点”，但只保留一个清晰的主任务，避免每种能力都争夺时间轴。
