# MiniMax H3 泛化提示词框架

本框架由跨题材、跨模式案例中反复有效的控制方法提炼而成。只学习控制关系，不保存、不检索、不拼接案例原文。

## 目录

1. 核心模型

## 1. 核心模型

把视频提示词理解为六层控制，而不是一段审美描述：

| 控制层 | 要解决的问题 | 可观察表达 |
|---|---|---|
| 目的 | 这条视频为什么存在 | 商品展示、剧情钩子、玩法演示、视觉包装 |
| 不变量 | 什么绝不能漂移 | 人物身份、产品结构、品牌字样、UI 布局 |
| 事件 | 画面中实际发生什么 | 动作顺序、对象关系、状态变化、结尾落点 |
| 摄影 | 观众如何看见它 | 景别、机位、构图、运镜、对焦、切镜 |
| 质感 | 它看起来属于什么世界 | 光线、色彩、材质、媒介、后期纹理 |
| 声音 | 观众如何听见它 | 对白、音乐、环境声、动作音效、卡点 |

先解决不变量、事件和摄影，再补质感。只写“高级、电影感、炸裂”不能形成可执行镜头。

## 2. 信息密度与时间轴

### 单镜头

使用连续链条：起始构图 → 主动作 → 相机反应 → 状态变化 → 结束构图。不要人为拆成多个时间段。

### 多镜头

按时间段分配功能，而不是平均分字数：

- 开头负责识别主体或建立钩子。
- 中段负责展示变化、冲突、功能或核心奇观。
- 结尾负责产品定格、情绪落点、文字收束或循环衔接。

每段只保留一个主要视觉任务。动作、镜头和转场之间写清因果，例如“扇面扫满画面形成遮挡，遮挡最满时切到下一场景”，比“炫酷转场”更可执行。

### 节奏

- 快节奏不等于镜头不断乱动；使用更短镜头、明确卡点和干净切换。
- 慢节奏不等于没有动作；使用缓慢推进、材质变化、眼神和声音细节维持张力。
- 一镜到底依赖连续运动、遮挡、材质匹配和空间贯通，不使用硬切语言。

## 3. 素材职责

### 绑定方式

用一句话绑定素材与职责：

```text
图1严格负责人物身份与服装；图2只负责产品外形和标签；视频1负责动作、机位与节奏；音频1负责音乐节拍。
```

随后把关键不变量展开为可观察特征。不要反复在每个镜头重新描述整套素材。

### 主次关系

当两份素材都包含人物或场景时，明确：

- 哪一份决定身份。
- 哪一份只提供姿势、光线或风格。
- 冲突部分以哪一份为准。

不要让“图1参考人物”和“视频1保持原人物”同时存在而不说明优先级。

### 素材最少化

只上传能提供独立信息的素材。重复素材不会自动提高一致性，反而可能造成平均脸、产品变形和风格串台。

## 4. 一致性与编辑

### 人物锁定

按需写明：同一身份、年龄、五官比例、发型发色、体型、服装版型、配饰数量。允许变化的通常只有表情、视线、姿势、呼吸和自然的头发或衣料运动。

### 产品锁定

按需写明：整体轮廓、长宽比例、部件数量、开合方式、标签文字、Logo 位置、颜色、材质和反光方式。涉及拆解或变形展示时，要求部件对齐、数量守恒并最终准确复位。

### 精准编辑

将编辑写成最小差异：

```text
严格复现视频1的时长、镜头、动作、构图、节奏和声音，只做以下变化：……其余内容保持不变。
```

多项编辑逐条列出最终状态。修改对象彼此有关联时补充同步关系，例如换背景后同步人物光线与地面阴影。

### 视觉换皮

把结构与视觉分开：

- 锁定：时间轴、动作功能、机位、运镜、转场、卡点。
- 重做：人物、服装、产品、环境、道具、色彩、品牌。

最终 Prompt 直接写新的成片内容，不写“原来是什么、现在改成什么”的解释。

## 5. 镜头、转场、文字和声音

### 镜头

把摄影词绑定到主体行为：

- “微距跟随瓶身冷凝水向下移动”比“产品特写”更明确。
- “人物转身时镜头保持眼平并横向跟移”比“电影级跟拍”更明确。
- “开火瞬间产生轻微后坐力抖动，随后恢复稳定”比“强烈手持感”更可控。

不要同时要求固定机位、环绕、快速推进和手持抖动，除非它们属于不同时间段。

### 转场

优先描述触发物和切换时刻：遮挡、甩动、闪光、材质匹配、动作匹配、UI 收拢、物体变形或声音重拍。避免只写“丝滑转场”。

### 文字和 UI

建立文字白名单并控制出现次数。把文字内容、位置、层级、字体气质、动效和停留时间分开写。UI 元素需要屏幕锁定时明确说明，不随相机透视漂移。

### 声音

按层编排：

- 对白：说话人、原文、情绪、口型和音色参考。
- 音乐：风格、节拍、进入和高潮位置。
- 环境声：空间真实性。
- 动作音效：只在具体动作触发。

声音参考与画面参考分开绑定；不要用一段模糊的“电影级音效”覆盖全部需求。

## 6. 题材适配

不要为不同题材套同一组字段，只强调决定成败的部分：

- 产品与电商：产品几何、材质、功能演示、卖点顺序和英雄定格。
- 品牌与时尚：人物态度、服装运动、构图节奏、品牌资产和质感统一。
- 剧情与短剧：人物关系、表演强度、视线、对白、正反打和结尾钩子。
- 动作与游戏：空间关系、动作因果、速度变化、碰撞反馈、第一/第三人称逻辑和 UI 锁定。
- 硬件、工业与具身智能：结构尺寸、部件数量、关节范围、操作顺序、接触受力、物理反馈和安全边界。
- 动画与风格化：渲染媒介、线条、材质、帧感和禁止混入的视觉体系。
- MV 与视觉包装：节拍、表演、文字动效、色块、遮罩和转场触发。
- Vlog 与纪实：拍摄者身份、设备感、不完美构图、对焦延迟、环境声和自然表演。
- 视频编辑：保留范围、最小变更、遮挡关系、光影适配和声音同步。

## 7. 常见失败

- **把案例当模板**：题材相似不代表镜头功能相同。回到用户目的重新设计。
- **参考素材不分工**：明确每份素材的唯一主责和冲突优先级。
- **风格词过多**：删除不能落到光线、材质、色彩或摄影行为的形容词。
- **动作过载**：缩减每段事件，给关键动作留出完成时间。
- **约束堆砌**：只禁止高概率且高损失的错误，避免否定词互相冲突。
- **重复锁定**：在全局声明一次不变量，分镜内只写该段新增变化。
- **文字失控**：使用唯一白名单，限制重复、错拼和新增字符。
- **编辑变重拍**：单点修改使用短指令，严格保留未点名内容。
- **伪完整 Prompt**：删除“可自行补充”“大概如此”“参考类似效果”等占位语。
