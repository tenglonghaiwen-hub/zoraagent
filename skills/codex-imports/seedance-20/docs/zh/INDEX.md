### 保留不动
- YAML frontmatter（YAML 块）原文不动
- 代码块（` ```bash `、` ```json `、` ```text `）原文
- 参考标签：`[Image1]`、`[Video1]`、`[Audio1]`、`@图1`、`@视频1`
- 品牌名 Seedance、模型代号
- 文件路径、API 端点、JSON Schema 字段

### 翻译对齐
所有术语翻译对齐 `references/vocab/zh.md`：
- `prompt` → `提示词`
- `shot` → `镜头`
- `take` → `镜头`
- `clip` → `片段`
- `sequence` → `序列`/`长故事`
- `beat` → `节拍`
- `reference` → `参考`
- `intent` → `意图`
