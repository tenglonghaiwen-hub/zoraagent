# 意图 vs 精度

Seedance 提示词不是逐像素的脚本。文字应该指挥意图；参考应该承载密集的视觉信息。

## 用文字表达

- 动作；
- 情绪意图；
- 摄影机行为；
- 时序；
- 光线变化；
- 音频；
- 约束。

## 用参考表达

- 身份；
- 产品设计；
- 动作范例；
- 摄影机节奏；
- 声音或音色质感；
- 材质外观。

短提示词应该密集，而非含糊。

要在操作层面执行这种拆分——决定一次生成的预算在身份保真度、动作大胆度和场景密度之间如何分配——请加载 `allocation-model.md`。
