# 分配模型 —— 决定提示词的预算花在哪里

*`intent-vs-precision.md` 的操作伴侣：每次生成都有有限的保真度预算，要求面面俱到的提示词只会让所有维度都变得平庸。在动笔前决定预算的去向。标签：[field] = 从业者报告 · [heuristic] = 待验证的默认。工艺指引汇编于 2026-06-11；不含平台可用性声明。*

## 前提 [field]

身份保真度、动作大胆度与场景密度争夺同一份生成预算。已知脆弱领域——细节稳定性、多主体一致性、文本渲染、面部微表情——是预算超支时最先失败的地方。一个镜头若想一次调用就拿到完美的脸、后空翻、拥挤的市场和一句台词，每一项都不会干净落地。

## 三种支出

| 支出 | 买到的 | 拉扯的 |
|---|---|---|
| 身份保真度 | 稳定的脸部、产品、logo、服装 | 动作幅度；任何大胆的动作都有漂移风险 |
| 动作大胆度 | 投入的动作、物理、编排 | 特写身份细节，尤其是面部和手部 |
| 场景密度 | 人群、分层环境、天气、道具 | 每主体稳定性；微小背景细节会降级 |

## 分配方法 [heuristic]

1. 命名主要支出 —— 这段镜头存在的唯一目的。一次生成只能有一个。
2. 挑一个次要支出；其他维度有意识地精简。
3. 将保真度卸载给参考：由 `[Image1]` 承载的身份，是文字不再花费的预算，从而将散文留给动作与时序。
4. 用其他维度支付主要支出：大胆动作会折损面部细节，所以情绪在身体中呈现并节制特写；密集场景会折损主体精度，所以主角主体在画面中保持大而少。
5. 在系列中重新锚定：链式生成会漂移，所以每隔几个片段就在身份上重新投入（使用原始参考，而非生成输出）。

## 已验证的分配 [field]

| 镜头 | 主要 | 次要 | 精简 |
|---|---|---|---|
| 产品广告 | 产品身份（参考锚定） | 一个材质动作节拍 | 场景密度、人群、天气 |
| 舞蹈 / 动作 | 动作大胆度（供体 `[Video1]`） | 经 `[Image1]` 重锚定的身份 | 面部特写、布景 |
| 世界建立镜头 | 场景密度与氛围 | 摄影机运动 | 角色身份（无近景主体） |
| 对白特写 | 面部稳定性（锁定摄影机） | 说出的一行台词 | 动作、背景活动 |

## 交易表 [field]

| 如果镜头需要 | 它要付出 |
|---|---|
| 大胆动作与一张特写脸 | 二选一；情绪通过姿态和走位表达，或切到另一段单独的特写镜头 |
| 许多主体 | 每主体身份精度；选一个主角，其余视为形状 |
| 可读的屏幕文字 | 不行 —— 文字移到后期 |
| 拥挤的画面与微小的产品细节 | 细节；将该产品节拍隔离在专属镜头中 |

## 动笔前清单 [heuristic]

对于序列项目，先分配当前片段，再分配完整故事。完整故事拥有目标与最终结局；当前片段拥有一个动作、一个端点，以及下一次交接所需的连续性锁定。未来节拍不计入当前提示词的预算。

1. 这段镜头是为了什么 —— 身份、动作，还是世界？
2. 哪些参考承载保真度，让文字不必承载？
3. 哪些维度被刻意精简，这种精简是否被写为约束？
4. 如果第 1 题答案是"三者都要"，那么哪些节拍应拆为单独的镜头或生成？
