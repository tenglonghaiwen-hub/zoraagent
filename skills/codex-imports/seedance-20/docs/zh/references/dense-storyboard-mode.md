# 密集分镜模式

当请求包含许多分镜、故事板节拍、动画分镜或多镜头描述时，使用本参考。

## 分类器

仅在用户明确希望一次生成内出现剪辑，且活跃平台/档案支持该结构时，选择 `dense_multishot`（密集多镜头）。当动作应保持连续时，选择 `phased_single_take`（分段单镜头）。不要将"单段连续拍摄"与硬切镜头标签混用。

## 密集多镜头规则

- 使用镜头标签。
- 给每个镜头一个动作和一个端点。
- 保持连续性锁定在镜头边界上可见。
- 不要让一段较短的生成过载过多地点、大型动作或角色更替。
- 后续生成提示词在先前的已接受片段被审阅前保持临时。

## 连续拍摄规则

使用"开始 / 然后 / 最后"。不使用镜头标签或硬切。描述一个摄影机路径、一个地理和一个物理动作链的各阶段。

## 2D 动画

对于 2D、动画或赛璐璐作品，使用动画制作词汇：图层、视差、保持帧、涂抹帧、冲击帧、赛璐璐阴影、线条抖动、背景横移与合成。除非用户明确希望混合仿真摄影机风格，否则避免使用摄影传感器、镜头、散景、ISO 和浅景深语言。

## 端点纪律

每个密集故事板节拍必须以一个已完成的视觉状态结束。如果端点不可见，下一段片段就无法安全继承。
