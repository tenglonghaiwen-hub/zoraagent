# 失败图谱

当序列或续拍输出失败时使用本参考。

| 症状 | 可能原因 | 主要修复变量 |
|---|---|---|
| 续拍从计划结尾开始 | 未审阅父级观察状态。 | 用观察到的结束状态替换开场。 |
| 动作重启 | 已完成节拍未标记为已发生。 | 添加已完成节拍排除。 |
| 未来事件提前出现 | 保留节拍泄露到提示词。 | 从提示词和端点中移除未来节拍。 |
| 延长过程中身份漂移 | 连续性来源替代了规范身份参考。 | 从规范图像重新锚定身份。 |
| 屏幕方向翻转 | 轴线未锁定或未有意重置。 | 声明屏幕方向或声明轴线重置。 |
| 开放动作停止 | 动作向量未继承。 | 携带主体/摄影机速度与方向。 |
| 摄影机相位重启 | 父级摄影机端点缺失。 | 从观察到的摄影机相位开始。 |
| 道具与前序片段矛盾 | 道具所有者/位置/状态未被追踪。 | 添加道具状态交接。 |
| 对白重复 | 已完成对白未被记录。 | 标记该行为已完成并继续音频相位。 |
| 延长质量下降 | 延长深度与漂移被忽略。 | 重新锚定或创建有意下一镜头。 |
| 参考角色污染 | 传递/忽略条款缺失。 | 拆分参考角色与排除项。 |
| 事件密度过高 | 数个节拍被编译进一条提示词。 | 将未来节拍重新分配到后续片段。 |
