# 画幅与交付平台

当规划专业构图、社交精简版、广播/网络交付、DCP/影院构图或活动版本时，使用本参考。

## 将创意画框与交付容器分开

| 层 | 决策 |
|---|---|
| 创意画幅 | 镜头设计的构图：16:9、9:16、1:1、4:5、1.85、2.39 |
| 平台或容器 | 网络、广播、DCP、IMF、社交、演示、推介会 |
| 安全区 | 面部、产品、字幕与 logo 必须保持可读的区域 |
| 重构图计划 | 裁剪、上下黑边、左右黑边、替代渲染或剪辑专属版本 |
| 文字策略 | 屏幕文字通常应在后期添加，而非生成进运动中 |

## 常见画幅

| 画幅 | 用途 | 提示词建议 |
|---|---|---|
| 16:9 | 网络、广播、演示、横向活动 | 电影场景工作的最强默认 |
| 9:16 | 竖屏社交、移动广告 | 让主角居中；避免边缘关键动作 |
| 1:1 | 社交网格、产品循环 | 对称产品构图效果好 |
| 4:5 | 社交信息流广告 | 留出头部与字幕空间 |
| 1.85 | 影院/叙事现代画框 | 为横向叙事构图，而非高产品文字 |
| 2.39 | 宽屏剧情、奢华广告 | 保护面部/产品不要过小 |

## 活动版本矩阵

| 版本 | 目的 | 规划备注 |
|---|---|---|
| 30 秒主角 | 完整故事 | 更多镜头、完整弧线、最强品牌/产品验证 |
| 15 秒精简版 | 付费社交/广播 | 保留钩子、产品验证、结束状态 |
| 10 秒缓冲 | 召回 | 一个动作节拍与最终产品或标题卡 |
| 6 秒缓冲 | 快速投放 | 一个视觉噱头/揭示/产品节拍 |
| 9:16 竖屏 | 移动 | 居中动作，避免宽广地理，字幕下方三分之一 |
| 1:1 或 4:5 | 信息流 | 产品与面部可在无边细节下阅读 |
| 无字幕 | 本地化/VFX | 无烧录文案、无字幕、无结束卡文字 |

## 提示词构图规则

- 早期说明目标画幅与构图目标。
- 当需要多种裁剪时，让面部、产品与 logo 远离画面边缘。
- 对于竖屏版本，简化摄影机运动并避免快速横向动作退出画面。
- 对于 2.39 或非常宽的画框，让主角主体足够大以存活生成与审阅。
- 对于标题卡、包框镜头、字幕与法律文本，偏好干净视觉底版加后期添加排版。

## 交付注意事项

在最终导出前始终核验活跃平台、买方、广播商、电影节或广告网络规格。技能可以规划画幅与裁剪策略，但合同规格控制母版。
