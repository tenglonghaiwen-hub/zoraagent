# 平台约束

last_verified: 2026-05-30

## 稳定约束

- 不要假设每个 Seedance 2.0 平台都有相同的功能。
- 不要凭记忆假设 API 可用性、价格、模型 ID、地区访问、上传限制、时长或肖像授权。
- 不要从上传的图像、声音或视频推断同意。
- 不要在无安全改写或明确授权上下文的情况下提供受保护角色、明星、品牌 logo、复制歌曲、精确场景或模仿人声的指令。
- 不要将真实人脸输入视为普遍允许或普遍禁止。某些平台限制直接人脸上传，同时允许经验证的虚拟肖像资产、可信同账户生成资产或已授权素材。
- 不要混用平台专属字段名：火山引擎的首尾帧角色、Runway 的 `promptImage` 位置与包装器模式不可互换。

## 平台专属声明

当用户询问 Dreamina、即梦、火山引擎方舟、BytePlus ModelArk、Runway、ComfyUI、Replicate、Higgsfield 或其他平台时，回答时附上平台名称与日期。清晰标记非官方/社区工具。

## 用户面向默认

平台支持因平台而异。在生产规划前检查当前的官方文档。
