# 字幕与本地化

当 Seedance 项目需要全球发布、字幕、字幕、强制叙述、混音、多语言提示词或市场专属文案时，使用本参考。

## 本地化计划

| 交付物 | 目的 | 提示词/后期边界 |
|---|---|---|
| 字幕 | 翻译口语对白 | 在后期从已批准脚本创建，而非生成为运动文字 |
| SDH 字幕 | 对白加重要声音提示 | 规划声音提示与说话者 ID；在后期撰写字幕 |
| 强制叙述 | 翻译标志、文字或非语言线条 | 避免烧录 AI 文字；保持干净底版 |
| 混音 | 本地化人声表演 | 使用短说话者回合、稳定构图与后期同步审阅 |
| M&E | 不含对白的音乐与音效 | 分别规划音频层 |
| 无字幕 | 无标题/下三分之一的画面 | 生成干净的背景/动作底版 |
| 市场文案 | 本地标语或法律声明 | 在法律批准后在设计/剪辑工具中添加 |

## 为字幕友好的画面提示

- 保持对白简短并分配给说话者。
- 为重要的口语台词使用稳定中景或中近景。
- 留出负空间用于字幕（当需要时）。
- 除非任务明确是粗略概念预览，避免生成字幕或小运动文字。
- 为文案变更的市场保留干净底版。
- 对于多语言对白，指定口语语言以及后期加字幕的语言。

## 阅读与摆放检查

对于专业输出，检查：

- 字幕不覆盖面部、产品声明、logo、法律免责声明或关键动作；
- 字幕为目标语言提供足够阅读时间；
- 说话者变更清晰；
- SDH 声音提示仅描述故事相关声音；
- 强制叙述仅在需要时使用；
- 换行保留意义；
- 正式/非正式称呼匹配地区与角色关系。

## 全球提示词交接

| 语言需求 | 安全措辞 |
|---|---|
| 中文提示词配合英文摄影机术语 | 中用于角色绑定，英文用于摄影机/镜头术语（如更清晰）；绝不用于规避 |
| 日文市场文案 | 保持生成镜头无字幕；在后期添加日文文案 |
| 韩文对白 | 短引述台词、稳定脸部构图、无头部转动 |
| 西班牙文字幕 | 规划字幕安全的下三分之一并避免烧录源文字 |
| 俄文本地化 | 交付无字幕底版加单独的俄文字幕/文案文件 |

## 文化本地化

询问必须本地化的内容：对白、产品声明、节日/季节、手势、标志、食物、服装、法律文本或音乐提示。不要假设字面翻译是市场就绪的本地化。

## 安全误报修复

混合语言措辞可以澄清良性制作上下文与参考角色，但它不能隐藏不安全内容。如果被屏蔽的提示词包含暴力、真实人物肖像、受保护 IP、性内容或类似规避的措辞，修复每种语言下的根本问题。
