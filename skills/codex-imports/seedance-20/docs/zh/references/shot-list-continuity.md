# 镜头列表与连续性

当用户请求电影场景、广告序列、多镜头规划、故事板、剧本到镜头列表转换或连续性修复时，使用本参考。

## 前期制作简报

仅收集会改变制作决策的内容：

- 目标：电影场景、产品广告、MV、预告片、社交精简版、内部推介、测试渲染；
- 受众与地区；
- 时长与目标平台；
- 主角、产品、角色或品牌；
- 参考与各自控制的内容；
- 版权/授权状态；
- 对白/音频需求；
- 画幅与交付平台；
- 截止日期、审批负责人与风险约束。

## 镜头列表字段

| 字段 | 范例 |
|---|---|
| 镜头 ID | `S01_SH03` |
| 时长 | `5s` |
| 模式 | T2V、I2V、R2V、FLF2V、剪辑、延长 |
| 目的 | 建立、揭示、展示、情绪转折、结束卡 |
| 主体/动作 | 产品旋转一次；角色放下信 |
| 镜头契约 | 中近景、锁定、50mm 人像压缩 |
| 参考 | `[Image1] product identity`、`[Video1] camera rhythm`、`[Audio1] beat` |
| 连续性锚点 | 服装、道具、屏幕方向、灯光状态、背景布局 |
| 开始画面 | 镜头开始处 |
| 结束画面 | 下一镜头交接或最终目标 |
| 音频 | 对白、环境声、音效、音乐提示、安静 |
| 风险 | 脸部漂移、logo 文字、手部复杂度、不安全肖像、提示词拦截 |
| 评审备注 | 接受、重试、剪辑、延长、替换 |

## 连续性账本

跨镜头追踪这些锚点：

| 锚点 | 记录内容 |
|---|---|
| 角色 | 标签、服装、发型、剪影、道具、情绪状态 |
| 产品 | 标签、logo、几何、材质、颜色、包框角度 |
| 地点 | 布局、左右地理、门/窗位置 |
| 屏幕方向 | 主体从左到右或从右到左移动 |
| 视线 | 每个角色看向哪里以及是否与反打匹配 |
| 灯光 | 主光方向、实用光源、一天中的时间、氛围 |
| 摄影机 | 镜头感、高度、稳定性、运动族 |
| 动作状态 | 前一端点发生了什么 |
| 声音状态 | 音乐、环境声、对白、同步提示 |

## 剧本到镜头列表

1. 提取戏剧或商业节拍。
2. 为每个节拍分配一条 Seedance 片段，除非该节拍极小且稳定。
3. 为每条片段选择脆弱锚点：脸、产品、文本、编排或端点。
4. 选择最安全的模式：I2V 用于身份/产品保持，FLF2V 用于精确端点，R2V 用于角色绑定动作或摄影机，剪辑用于单层变化，延长用于续拍。
5. 为每个镜头创建镜头契约与连续性锚点。
6. 仅在镜头列表稳定后再撰写提示词。

## 三镜头商业广告模式

| 镜头 | 目的 | 提示词脊柱 |
|---|---|---|
| 1 | 问题或世界 | 广角或中景环境，简洁动作，建立产品上下文 |
| 2 | 产品/材质验证 | 近景或微距，锁定或缓慢推镜，材质细节与一个音效 |
| 3 | 主角包框/结束状态 | 产品三分之四角度，干净灯光，logo 保持，标语后期处理 |

## 交接规则

- 当连续性重要时，使用已接受尾帧作为下一首帧参考。
- 保持服装、产品朝向、屏幕方向与灯光方向稳定，除非故事明确改变它们。
- 若一条提示词产生了良好的表演但糟糕的产品/logo，剪辑或合成产品层而非重生整个镜头。
- 若一条镜头失败三次，简化镜头契约或将动作拆为两条片段。

## 序列状态交接

对于有状态序列，将松散连续性账本替换为片段血统：

- `project_id`、`clip_id` 与 `parent_clip_id`；
- 计划的开始与计划的结束状态；
- 评审后的观察开始与观察结束状态；
- 已完成节拍、当前片段节拍与保留的未来节拍；
- 连续性锁定与允许的变更；
- 转入、转出、开放动作向量与交接要求。

仅定稿当前未解决的片段提示词。后续镜头卡片在前序已接受镜头被评审前保持临时。
