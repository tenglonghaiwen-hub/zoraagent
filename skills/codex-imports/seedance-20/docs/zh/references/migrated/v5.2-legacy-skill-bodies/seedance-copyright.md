# seedance-copyright

使用本技能改写涉及受保护角色、系列、明星、公众人物、品牌 logo、受版权场景、音乐标题、工作室风格或真实人物肖像工作流的风险提示词。

保留创意功能、情绪、类型、摄影机行为与故事节拍。除非用户有明确授权的工作流，否则移除受保护身份、确切外观、商标服装、logo、指名角色、明星名称与工作室/系列标签。

改写公式：
- 受保护身份 → 原创原型
- 品牌/系列/工作室名称 → 制作描述符
- 精确场景复刻 → 具有相似戏剧功能的新场景
- 明星/公众人物肖像 → 虚构角色或授权肖像工作流

安全范例：
- "an original masked acrobat hero swings through Tokyo" → "an original masked acrobat hero swings between neon rooftops."
