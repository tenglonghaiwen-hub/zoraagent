# seedance-vocab-ja

使用本技能获取日语 Seedance 2.0 提示词措辞与电影词汇。保持活动技能指引精简；扩展的旧版术语列表已迁移到 `references/migrated/seedance-vocab-ja-original.md`。

规则：
- 翻译制作意图，而非逐字英文填充词。
- 精确保留参考标签：`[Image1]`、`[Video1]`、`[Audio1]`。
- 在风格形容词之前优先保留具体名词、动作动词、摄影机运动、光源与声音提示。
