# 交付与 QC

当输出必须被审阅、交付给客户、准备平台上传、本地化、归档或作为专业活动的一部分交付时，使用本参考。

## 交付预检

| 领域 | 检查 |
|---|---|
| 画面 | 帧率、分辨率、画幅、裁剪、安全区、稳定化、闪烁、条带 |
| 调色 | 工作空间、外观备注、HDR/SDR 目标、产品/品牌颜色、法律范围（如需要） |
| 音频 | 同步、响度、真峰值、对白清晰度、stems、M&E、应静默处的静默 |
| 文字 | 字幕、字幕、强制叙述、屏幕文案、标题安全摆放 |
| 连续性 | 服装、道具、屏幕方向、产品朝向、灯光方向、尾帧交接 |
| 权利 | 参考、音乐、人声、肖像、产品/品牌授权、素材库许可 |
| 元数据 | 工作 ID、模型/平台、提示词版本、种子/设置（如可用）、源 URL、审批负责人 |
| 版本化 | 主角、精简版、竖屏、方形、无字幕、本地化、归档 |
| 人工 QC | 以正常速度观看所有输出并在脆弱画面暂停 |

## 命名模式

使用一致的名称：

`PROJECT_CAMPAIGN_VERSION_RATIO_LANG_DATE_STATUS`

范例：

`LUMA_BOTTLE_HERO_15S_9x16_TEXTLESS_2026-05-30_REVIEW01`

## 客户审阅包

包含：

- 概念/剧本阐述；
- 镜头列表与已接受提示词；
- 参考角色映射与权利备注；
- 导出的审阅链接/文件；
- 已知问题与推荐修复；
- 审批问题；
- 交付规格假设。

## QC 失败路由

| 失败 | 路由 |
|---|---|
| 面部/产品/文字漂移 | I2V 锁定、剪辑通过、后期合成或从稳定帧重生 |
| 连续性不匹配 | 更新连续性账本并仅重生受影响镜头 |
| 调色不匹配 | 先调色/合规；仅当灯光意图错误时重生 |
| 字幕/文字问题 | 移除生成文字并在后期添加排版 |
| 响度/同步问题 | 修复混音或剪辑时序；不仅依赖提示词修复 |
| 不安全或权利问题 | 改写为原创/已授权素材并记录权利 |

## 完成定义

专业 Seedance 资产仅在创意负责人批准镜头、权利映射干净、连续性被追踪、后期交接明确且交付目标通过人工 QC 时才算完成。
