# 音频后期与交付

当 Seedance 工作涉及对白、声音设计、音乐、stems、M&E、混音、同步或最终交付检查时，使用本参考。

## 提示词层音频

使用提示词音频指挥故事时序与情绪：

- 对白：简短、加引号、分配给一名说话者；
- 环境声：房间底噪、交通、雨声、人群床、机械嗡鸣；
- 音效：一两个故事相关的声音，与可见动作绑定；
- 音乐：广义节奏、能量、配器或安静；
- 同步提示：端点处的门砰、最终帧上的产品咔嗒、下拍上的光脉冲。

除非权利与平台支持明确，避免对受保护歌曲、真实人声或已授权表演的精确复制声明。

## 后期层音频交付物

| 交付物 | 目的 |
|---|---|
| 完整混音 | 最终立体声/5.1/Atmos 或平台要求的混音 |
| 对白 stem | 用于剪辑、混音和清理的口语台词 |
| 音乐 stem | 仅音乐层 |
| 音效 stem | 音效与设计声音 |
| M&E | 不含原始对白的音乐与音效，用于本地化 |
| 印刷母版 | 已批准的最终母版混音 |
| 混音指南 | 说话者时序、音色、发音、停顿 |
| 响度报告 | 交付目标合规证据 |

## 音频规划模板

`Dialogue: [speaker/line/language]. Ambience: [bed]. SFX: [visible sync cue]. Music: [tempo/mood or none]. Reference: [Audio1 role]. Post: [stems/M&E/loudness/sync notes].`

## 同步与响度检查

对于专业交付，检查：

- 对白与最终画面的唇形同步；
- 帧率转换后的音乐/音效同步；
- 对白未被音乐或音效掩盖；
- R2V 工作流中没有意外的源视频音频；
- 按买方/平台规格的响度目标与真峰值；
- 若本地化需要，M&E 或 stems 存在。

## 常见修复

| 失败 | 修复 |
|---|---|
| 对白去同步 | 更短台词、锁定构图、减少头部动作、一名说话者 |
| 错误说话者 | 标记说话者并分割回合 |
| 音乐压过台词 | 对白期间移除音乐，保留房间底噪 |
| 音频参考被忽略 | 将 `[Audio1]` 映射到节奏或情绪，并将可见事件绑定到它 |
| 视频与音频参考冲突 | 静音视频参考或将视频分配为仅摄影机 |
| 本地化不可能 | 在最终剪辑前规划 M&E/stems 与无字幕画面 |
