# 叙事框架

一段短的 Seedance 片段在拥有一个可见的决定或一个可见的转变时效果最好。模型不需要完整的情节；它需要一个清晰的前置状态、动作与改变后的最终状态。

## 有用的片段节拍

| 节拍 | 改变的内容 | 范例 |
|---|---|---|
| 抵达（Arrival） | 主体进入新空间。 | 快递员到达一扇上锁的屋顶门前。 |
| 揭示（Reveal） | 隐藏的信息变得可见。 | 条形灯照亮产品标签。 |
| 决定（Decision） | 角色通过姿态做出选择。 | 角色放下信封，望向门。 |
| 转变（Transformation） | 材质或环境发生变化。 | 霜在玻璃上扩散并在 logo 处停下。 |
| 反转（Reversal） | 预期动作改变方向。 | 纸飞机调头飞回寄件人。 |
| 追逐（Pursuit） | 一个主体缩短距离。 | 无人机穿越雨幕追踪跑者。 |
| 接触（Contact） | 两个元素相遇。 | 钥匙触碰锁孔，蓝光迸发后熄灭。 |
| 消失（Disappearance） | 主体退出、消散或隐藏。 | 列车灯光渐隐于雾中。 |

## 节拍公式

`前置状态 -> 可见动作 -> 改变后的最终状态`

摄影机、灯光和音频应支撑这个节拍，而非与之竞争。如果提示词包含多个节拍，拆分为单独的片段，或撰写一个刻意的按时间分段序列。

## 微故事清单

主体已命名或标注。动作是动词，而非情绪。场景包含一个有用的环境细节。摄影机有起点和终点。光源有动机。声音层要么支撑节拍，要么保持安静。最终画面与第一帧不同。

## 序列工作的三个尺度

故事层：初始条件 -> 目标 -> 升级 -> 最终结局。本层解释项目为何存在，但并不授权当前提示词出现每个事件。

序列层：Clip 01 职责 -> Clip 02 职责 -> Clip 03 职责 -> 收束。每个片段有一个叙事职责和一个完成的端点。

片段层：已发生 -> 实际开场状态 -> 当前动作 -> 物理后果 -> 已完成端点 -> 保留的未来动作。

## 范围防火墙

故事上下文启发动机、表演、氛围和节奏。故事上下文不允许当前片段执行未来事件、跳过物理交接状态、揭示保留信息，或假设尚未被已接受画面达到的预定结局。
