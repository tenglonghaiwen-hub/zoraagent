# 摄影机镜头语言

当用户需要导演/DP 级别的镜头设计而非泛化电影形容词时，使用本参考。

## 镜头契约

每个专业镜头应声明：

| 字段 | 提示词决策 |
|---|---|
| 景别 | 极广角、广角、中广角、中景、中近景、近景、极近景、微距 |
| 角度 | 平视、低角度、高角度、俯视、侧面、过肩、插入、产品三分之四 |
| 镜头感 | 广角空间能量、自然 35mm 透视、人像压缩、微距材质细节 |
| 摄影机支撑 | 锁定、手持、滑动、滑动、起重机、无人机、稳定器、虚拟产品台 |
| 运动 | 推镜、拉镜、横向跟踪、环绕、摇、倾、升降、起重机升起、揭示、调焦 |
| 主体关系 | 摄影机跟随、引导、发现、保持、观察或与主体走位 |
| 开始画面 | 第一个可读构图 |
| 结束画面 | 改变状态、姿态、揭示、产品主角或连续性交接 |
| 脆弱锚点 | 脸部、手部、logo、文字、产品形状、服装、道具位置 |

提示词模式：

`Shot: [size/angle/lens feel]. Camera starts [composition], [one movement] at [speed] while [subject action], ending on [clear endpoint]. Preserve [fragile anchors].`

## 景别用途

| 景别 | 用于 | Seedance 注意事项 |
|---|---|---|
| 极广角 | 尺度、抵达、环境 | 小面部/logo 会漂移；不要要求面部表演 |
| 广角 | 走位、舞蹈、动作、产品在环境中 | 让动作简洁可读 |
| 中景 | 对白、产品使用、交接 | 角色商业广告的良好默认 |
| 近景 | 情绪、材质、唇形同步、产品细节 | 保持摄影机稳定且动作小 |
| 微距 | 材质、食物、珠宝、机械 | 避免大动作与文字重绘 |

## 摄影机运动语法

- **锁定：** 用于唇形同步、产品身份、文字、logo、精确 VFX 与连续性锚点。
- **滑动/推镜：** 用于发现、领悟、亲密、产品揭示。
- **横向跟踪：** 用于旅行、列队、编排、经过的前景层。
- **环绕：** 用于产品主角与雕像般的主体；如果身份必须从一个角度保持稳定则避免。
- **起重机/无人机：** 用于尺度、抵达、地理、揭示；避免对白或微小产品文字。
- **手持：** 用于写实或张力；当身份重要时保持运动微妙。
- **调焦：** 用于两个锚定物体之间的注意转移；避免与复杂摄影机运动堆叠。

## 走位与覆盖

对于多镜头场景，保持摄影机语法有动机：

1. 建立地理与屏幕方向。
2. 转向角色/产品动作。
3. 仅在细节改变故事时使用近景细节。
4. 以可成为下一首帧参考的画面结束每条片段。

覆盖模式：

`Shot 1 wide establishes [space/screen direction]. Shot 2 medium follows [action]. Shot 3 close-up reveals [consequence]. Continuity: same wardrobe, prop, light direction, and eyeline.`

## 专业避免清单

避免：`cinematic camera`、`dynamic shot`、`epic zoom`、`film look`、`Hollywood style`、`beautiful composition` 等无物理镜头选择的措辞。

替换为：景别、支撑、运动、主体关系、有动机的光、端点与脆弱锚点。
