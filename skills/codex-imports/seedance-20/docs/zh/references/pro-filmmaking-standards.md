# 专业电影制作标准

last_verified: 2026-05-30

当 Seedance 工作必须支持导演、摄影指导、剪辑师、制片人、本地化团队、商业代理或交付/QC 团队时，使用本参考。将这些标准视作工作流指引，而非视频生成平台能直接渲染或导出每个技术交付物的承诺。

## 源边界

| 领域 | 首选源类型 | 在本技能中使用 | 边界 |
|---|---|---|---|
| 镜头设计 | ASC、摄影指导教育、制作镜头列表实践 | 将创作意图翻译为镜头契约。 | 不要对短 AI 片段过度规定逐帧完美的摄影机物理。 |
| 连续性 | 剧本监督与制作连续性实践 | 追踪服装、道具、屏幕方向、视线、灯光状态与尾帧交接。 | AI 连续性是概率性的；对脆弱锚点使用参考与更小镜头。 |
| 调色 | ACES 文档、AMF、交付合作伙伴指引 | 追踪调色意图、片场风格、LUT/CDL/LMT 备注、HDR/SDR 期望。 | 提示词可以请求外观；最终调色仍必须在调色工具中核验。 |
| 画幅 | 交付合作伙伴规格、DCI/ISDCF、平台规格 | 将创意构图与交付容器和安全区分开。 | 不要假设每个平台都支持每个画幅或裁剪。 |
| 音频 | ITU BS.1770、EBU R128、ATSC A/85、交付合作伙伴混音规格 | 规划对白、环境声、音效、音乐、M&E/stems、响度与同步检查。 | Seedance 提示词音频不是认证的最终混音。 |
| 字幕 | Netflix 时序文本、WebVTT、可访问性与字幕规则 | 规划字幕、SDH、强制叙述、阅读时间、摆放与本地化备注。 | 不要依赖生成的烧录文字作为最终交付字幕。 |
| 交付/QC | SMPTE IMF、DPP、Netflix 交付规格、DCI | 为帧率、分辨率、调色、音频、字幕、无字幕、元数据与人工 QC 创建预检。 | 始终遵守工作实际签约的买方/平台规格。 |

## 专业运行脊柱

1. **简报：** 定义客户/创意目标、受众、地区、时长、画幅、可交付物、参考、权利、审批负责人与硬约束。
2. **前期制作：** 创建剧本阐述、参考映射、镜头列表、连续性账本、调色/音频/本地化意图与风险日志。
3. **生成计划：** 拆分为稳定镜头。每条 Seedance 片段分配一个可见节拍、一个摄影机想法与一个端点。
4. **评审回路：** 在延长或剪辑前评估身份、产品、动作、摄影机、连续性、音频同步、文字、安全与权利。
5. **后期计划：** 剪辑、合规、稳定化、声音、调色、字幕、版本化、无字幕与归档元数据。
6. **交付/QC：** 检查规格、命名、帧率、分辨率、调色流水线、响度、字幕、安全区、权利备注与人工评审。

## 专业回答契约

对于专业电影制作请求，返回：

- 制作阶段与角色：导演、DP、剪辑师、制片人、声音、本地化或交付；
- 对易变平台声明的假设与源日期注意事项；
- 镜头契约或工作流清单；
- 参考与权利映射；
- 连续性锚点；
- 当输出将离开提示词阶段时的后期/交付备注。

当用户请求电影、商业、活动、本地化包或交付就绪工作流时，避免仅给出最终提示词。
