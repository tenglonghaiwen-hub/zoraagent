# API 工作流

last_verified: 2026-06-20

将本参考用于火山引擎、BytePlus、Runway、fal、提供商/路由平台或包装器上的 Seedance 2.0 操作规划。它不是静态 API 契约。在实施前始终重新检查活跃的提供商文档或控制台。

## 平台关卡

| 平台 | 使用时机 | 必须重新检查 |
|---|---|---|
| 火山引擎方舟 | 面向中国的官方方舟工作流、模型 ID、任务生命周期、首尾帧角色、`return_last_frame`、网络搜索工具与虚拟肖像资产。 | 模型 ID、地区、授权、模式、价格、时长、分辨率、人脸/参考策略 |
| BytePlus ModelArk | 国际 BytePlus 文档或控制台工作流。 | JavaScript 渲染的价格/模型页面、账户访问、地区、确切模型 ID、上传/文件规则 |
| Runway | 使用 `seedance2`、托管上传与 Runway 计划/地区约束的 Runway web/API/MCP 工作流。 | 时长、画幅、计划、地区、SDK 字段支持、音频参考组合规则 |
| 提供商/路由 API | EvoLink、OpenRouter、Kie.ai、PiAPI、LaoZhang、Runware、ModelsLab、AI/ML API、MuAPI、SeeGen、Segmind 或类似平台。 | 基 URL、模型 ID、任务端点、轮询端点、回调/Webhook 支持、计费单位、文件托管、参考模式、人脸策略、输出 URL 寿命、权利条款 |
| 面向中国的官方平台 | 字节跳动 Seed、火山引擎方舟、BytePlus ModelArk、豆包、即梦/剪映、CapCut/剪映。 | 语言/地区、账户层级、企业或个人访问、身份验证、肖像/虚拟化身流程、控制台授权、确切文档日期 |
| 包装器 API | 通过第三方提供商的快速原型。 | 名称、价格、审核、时长或人脸支持是否为包装器专属 |

## 异步任务生命周期

1. 使用带源日期的模型 ID、提示词、时长、画幅/大小、分辨率与参考文件创建任务。
2. 存储任务 ID、提供商、请求日期、模型 ID 与提示词版本。
3. 轮询或使用 SDK 等待助手直到完成或失败。
4. 检索输出 URL、可选尾帧、日志/错误以及在提供时附上的审核/失败原因。
5. 保存输出及元数据以支持可复现性。
6. 仅通过活跃提供商的当前文档取消、删除或列出任务。

## 请求清单

- 提示词包含一个可见节拍、一个摄影机运动、物理光线、声音意图与约束。
- 模式明确：T2V、I2V、V2V、R2V、FLF2V、剪辑或延长。
- 参考角色明确且合法：首帧、尾帧、身份、产品、动作、摄影机、时序、音频或风格。
- 音频参考与文本提示词以及在平台要求该组合时的有效图像/视频参考配对。
- 首尾帧请求不会悄悄混合不兼容的视频/音频参考模式，除非活跃文档允许。
- 真实人物、人脸、肖像与人声输入已获授权且平台支持。
- 价格、时长、分辨率、地区、配额与模型 ID 已附核验日期。

## 提供商说明

火山引擎文档是 `doubao-seedance-2-0-260128`、`doubao-seedance-2-0-fast-260128`、`doubao-seedance-2-0-mini-260615`、首尾帧角色与方舟任务流的当前来源。Mini ID 在 6 月 20 日核对的官方公告中仍处于 6 月 22 日前的试用把关。引用价格时仅附日期与注意事项。

BytePlus 文档是 `dreamina-seedance-2-0-mini-260615` 与 `dreamina-seedance-2.0-mini` 价格行标签的当前来源。视作 BytePlus 专属；在实施前重新检查 Model Playground/API 访问、时长、分辨率与价格。

Runway 文档是 Runway 的 `seedance2` API 平台、`runway://` 上传、时长、参考数量规则与 SDK 注意事项的当前来源。不要将 Runway 字段名复制到火山引擎范例中，反之亦然。

提供商/路由平台是集成的便利工具，而非权威模型规格来源。截至 2026-06-20，本仓库追踪 EvoLink、OpenRouter、Kie.ai、PiAPI、LaoZhang、Runware、ModelsLab、AI/ML API、MuAPI、SeeGen 与 Segmind 为提及 Seedance 2.0 访问的公开页面或文档。使用活跃平台自身的文档获取模型 ID 与字段，永不跨提供商合并模式。

中文检索结果在使用前需要分类。官方字节跳动/火山引擎/BytePlus/豆包/即梦/剪映页面可支持面向中国的平台指引。托管工作流、中文博客、价格对比与商业伙伴新闻可提供上下文，但除非它们链接到提供方自有的 API 文档，否则不是公开 API 契约。

BytePlus 页面可能按 JavaScript 渲染。不要从不完整的静态抓取推断实时价格或模型 ID。

## 错误与风险应对手册

| 症状 | 可能原因 | 首要修复 |
|---|---|---|
| 403 或模型不可用 | 地区、计划、授权、供应商许可或提供商关卡 | 检查平台专属访问文档与账户控制台 |
| 仅音频请求失败 | 活跃平台要求图像/视频加上带音频的提示词 | 添加有效视觉参考并声明音频角色 |
| 首尾帧被拒 | 不兼容的模式混合或错误的角色字段 | 使用提供商的首尾帧字段名，并在需要时移除视频/音频参考 |
| 人脸/肖像上传被屏蔽 | 真实人物策略、验证或资产库要求 | 使用已授权的虚拟肖像路径或原创角色改写 |
| 延长后输出漂移 | 弱的尾帧连续性或过多变更变量 | 使用返回尾帧作为下一首帧并变更一个变量 |
| 价格估算错误 | 过时的价格页面或包装器专属计费 | 在引用前重新检查提供商价格页面/控制台 |

## 生产就绪

维护一份运行账本，包含：提供商、模型 ID、提示词、模式、参考、时长、分辨率、生成音频标志、任务 ID、输出 URL、尾帧、核验日期与失败备注。这让提示词修复成为可能，并防止过时的来源声明渗入面向用户的指引。
