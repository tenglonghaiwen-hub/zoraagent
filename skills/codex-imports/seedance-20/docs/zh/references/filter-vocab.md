# 过滤安全词汇

使用专业的、非图形的、制作上下文语言。不要使用本参考来绕过安全系统。

| 风险表面 | 更安全的制作措辞 |
|---|---|
| 暴力撞击 | 高能碰撞、非图形动作节拍 |
| 武器特写 | 安全持有的道具对象、动作场景摆拍 |
| 血腥 | 红色织物强调色、彩色液体、非图形余波 |
| 伤害 | 可见疲劳、戏剧张力、角色痛苦 |
| 战斗 | 编排动作序列、摆拍对峙 |
| 明星面部 | 具有广泛原型特征的原创角色 |
| 品牌 logo | 通用产品标志或空白标签 |
| 指名系列 | 具有相似类型功能的原创世界 |

保留意图。改变风险表面措辞。

## 误报减少

仅对被误解的安全提示词使用此方法。修复是澄清，而非规避。

| 模糊措辞 | 更安全的澄清 |
|---|---|
| 黑暗战斗场景 | 摆拍对峙、编排动作节拍、无图形伤害 |
| 桌上的刀 | 桌上的安全道具对象，不用于伤害 |
| 紧张人质氛围 | 锁门悬念场景，无约束且无伤害 |
| 血红光线 | 深红实用光、红色织物强调色、无伤害 |
| 复制此人 | 原创已授权角色参考，仅保留用户拥有的身份 |
| 让它像这部电影 | 具有相似摄影机功能、调色、节奏与类型情绪的原创场景 |
| 可怕的孩童娃娃 | 阴森房间中的古董玩具道具，无真实儿童 |

## 多语言澄清

当使安全提示词更清晰时允许语言混合：

- 当更精确时保持英文技术摄影机术语：`locked medium shot`、`35mm lens`、`slow dolly-in`。
- 当更简短时保持中文角色绑定：`@图1锁定主体身份`、`@视频1仅参考运镜`。
- 对白保持说话者语言，并让安全/所有权约束保持明确。
- 不要将不安全内容翻译成另一种语言作为变通。
- 如果提示词仍然失败，改变风险的创意表面，而非仅改变语言。
