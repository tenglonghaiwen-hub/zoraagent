# 社区源方法论

last_verified: 2026-05-30

挖掘提示词语料、论坛、Reddit 帖子、中文指南、俄文指南或包装器文档时使用本参考。

## 允许的提取

- 提示词结构。
- 时序语法。
- 摄影机、灯光、动作、音频、VFX 与约束词汇。
- 参考角色语言。
- 失败模式与安全修复。
- 源元数据：URL、作者账号、语言、日期与平台。

## 不允许的提取

- 受保护角色、系列、精确场景、工作室或歌曲作为可重用范例。
- 明星、公众人物、私人人物或人声模仿提示词。
- 绕过过滤器或规避审核的指令。
- 将包装器价格作为通用 Seedance 价格。
- 无法重新核实的私密频道声明。

## 语料标签

| 标签 | 含义 |
|---|---|
| `safe-example-candidate` | 可通过轻微清理重写为活跃文档。 |
| `safe-structure-only` | 仅挖掘结构/词汇；不要复制提示词内容。 |
| `ip-risk` | 包含受保护角色、系列、工作室、精确场景或歌曲。 |
| `real-person-risk` | 包含真实面部、公众人物、明星或人声模仿风险。 |
| `brand-risk` | 包含需要授权的品牌/logo/产品身份。 |
| `violence-risk` | 需要非图形摆拍动作重写或排除。 |
| `low-quality` | 太过泛化、不连贯或 slop 过重无法挖掘。 |

## 变换规则

原始社区提示词应成为原创安全范例。用原型替代受保护名称，用用户拥有/产品占位符替代指名品牌，用授权门控语言替代真实人物参考。

## 序列范例规则

不要将商业创作者的续拍提示词复制为黄金范例。仅提取可重用结构：实际结尾、已完成动作、当前片段工作、保留的未来动作、参考传递边界与端点。重写为具有合成项目 ID 与明确合成 fixture 的原创序列范例。
