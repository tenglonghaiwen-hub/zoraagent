# 能力图 —— 围绕限制设计到优势中

*Seedance 2.0 最擅长什么，如何提取每个优势，以及围绕什么设计。在提示词规划前加载。标签：[official] = 字节跳动/fal/方舟文档 · [field] = 从业者报告 · [heuristic] = 待验证的默认。最后核验 2026-06-09。这些行背后的机制位于 `model-mechanics.md`。*

## 设计 INTO 这些

| 能力 | 提取动作 |
|---|---|
| 一次调用中的多镜头 [official] | `Shot 1:/2:/3:` 标签 · 每个一个动作 + 一个摄影机 · Standard 档 · 10–15 秒/`auto` · 镜头×秒预算 |
| 原生同步音频 [official] | 命名具体声音；对白作为屏幕上的自然引述行；短行；干净正面参考；音效>音乐>对白 —— 先测试对白 |
| 角色分离参考 [official] | 每个资产一个角色 **+ 排除**（"仅动作，无外观"） |
| 通过 @Video 的动作传递 [official/field] | 编排/摄影机节奏供体片段 + 身份 @Image |
| 通过 @Audio 的音频作时钟 [field] | "在 @Audio1 的节拍上剪辑；转折落在 drop 上" |
| 首尾帧 [official] | 锁定端点；提示词 initiate→travel→resolve；转变与匹配剪辑 |
| 字面摄影机动词 [official] | 每个镜头一个有动机的运动 |
| 物理 [official 声明] | 物理动词与后果，而非姿态形容词 |
| 慢动作 [official] | Standard 档；在单一关键动作上 |
| 转变 [field] | 端点状态 + 持久载体；困难情况 → FLF 分解 |
| 2D/动画 [field] | 媒介语法：赛璐璐层叠绘制背景，sakuga vs 保持帧，冲击帧/速度线/涂抹；无镜头/DOF 论述 —— 完整语法在 `[ref:2d-anime-grammar]` |
| 格式与 `auto` [official] | 21:9 用于影院；`auto` 按复杂度决定时长 |
| 多语言 [official/field] | 中锚点用于质感/情绪；保持参考标签精确 |

## 围绕这些设计

对于相连生成，通过保持每条片段小、记录已接受观察状态、保持精确参考角色并在延长深度或可见漂移增加时重新锚定来围绕连续性漂移设计。这是工作流指引，而非确定性平台保证。

平台时长上限是活跃平台事实，而非通用 Seedance 事实；音频在分离调用间不连续，因此如需要则在后期配乐 [official] · 屏幕文字 → 后期 [official] · 否定召唤 —— 通过构图排除 [field] · 微小细节（远距离脸、手、logo）降级 [field] · 面部微表演最弱 —— 情绪在身体/走位中呈现，节制特写 [heuristic] · 重复链式生成后可见漂移 —— 重新锚定原始参考 [field] · 多人物镜头中角色↔道具物理脆弱 —— 让接触保持简单或出画，使用三层动作层级 [field] · 快速档行为是平台专属 [field] · 种子 = 稳定器，而非锁定 [official]。

## 竞争上下文 *(2026-06-14)*

原生音频不再是 Seedance 独有差异化 —— 截至 2026 年中 Veo 3.1、Sora 2、Kling 3.0、Runway Gen-4.5、Hailuo 2.3 与 Vidu Q3 都附带它 [tech-press]。以组合中仍具特色的东西打头 —— 单次通过多模态参考（文本+图像+视频+音频一起）、从单条提示词出发的多镜头与多语言唇形同步 —— 而非将原生音频作为头条销售。官方原生分辨率是 480p/720p；1080p 是平台专属（见 `api-status.md`）。
