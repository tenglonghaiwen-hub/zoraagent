# 类型指南

使用类型指引来选择优先级，而非添加空洞的风格词。每种类型仍需要一个主体、一个可见节拍、摄影机逻辑、物理光线、音频意图与约束。

## 产品广告

保持产品身份。使用一次揭示、干净反射、材质专属光与受控摄影机运动。将 logo、标签、形状与材质约束放在开头附近，尤其是在 I2V 或 R2V 中。优先偏好移动的光、雾、冷凝、粒子或围绕产品的摄影机，而非变形产品本身。

## 短剧

使用姿态、走位、沉默与可见的情绪转折。让提示词锚定一个节拍：角色进入、注意到、决定、隐藏、揭示或离开。通过标签分配每个角色并保持对白简短。当面部表演重要时使用锁定或缓慢推镜摄影机。

## 动作

使用一个目标、一个障碍、一个摄影机运动与明确的角色标签。指定力量、时序与后果：谁躲避、谁落地、什么破碎、什么保持完整。如果手部、面部或道具重要，减少动作复杂度或拆为片段。

## 动画

使用媒介、线条质量、调色板、变形、节奏、质感与动作节奏。避免指名工作室、系列或艺术家标签。描述原创角色形状、背景纹理、调色板与动作：柔和挤压拉伸、阶梯有限动画、剪纸视差、黏土式定格动画或干净 3D 玩具写实。

## 音乐 / 节拍同步

将节拍映射到可见的变化：步伐、剪辑、光脉冲、物体冲击或摄影机重音。除非有文档化的平台行为支持精确播放，否则使用 `[Audio1]` 处理节奏、能量、情绪或速度。避免复制受保护的人声、旋律或表演身份。

## 美食与生活方式

优先考虑质感、蒸汽、手部动作、实用光与自然声音。让动作简洁：倒、提、切、搅、置、咬、擦、折或开。使用近距构图与有动机的环境音频，取代宽泛的生活方式形容词。

## 风景与自然

使用慢速摄影机、氛围层、天气动作与自然声音。通过前景动作、中景主体与背景揭示构建深度。避免在同一画面中同时拥挤动物、天气、摄影机运动与延时变化。

## VFX 与转变

陈述来源、材质、运动路径、交互与端点。保护身份锚点如面部、logo、道具与文字。如果转变是故事节拍，转变环境或可消耗的对象，除非用户明确希望主体变化。
