# 连续性 QC

在序列提示词定稿前与生成功镜头评审后，使用本参考。

## 无说明则硬性失败

不要静默改变：

- 规范身份；
- 服装；
- 产品身份；
- 产品几何；
- 道具归属；
- 地点；
- 车辆身份；
- 持久环境；
- 精确参考标签；
- 已接受已完成节拍状态；
- 父级片段血统。

## 警告除非声明

对姿态、画面位置、屏幕方向、动作向量、摄影机相位、对焦状态、灯光相位、情绪状态、环境声、音乐相位或活跃对白中的未说明变更发出警告。

仅当在过渡、允许变更、已接受偏差、有意轴线重置或有意下一镜头下声明时，才允许变更。

## 边界检查

在后续提示词发布前，核实：

- 前序已接受状态；
- 后续 `parent_clip_id`；
- 前序 `observed_end_state`；
- 后续 `planned_start_state`；
- 已完成节拍被排除；
- 未来节拍被排除；
- 精确标签被保留；
- 当前提示词仅覆盖当前片段。
