# Seedance 研究快照

last_verified: 2026-05-30

本快照记录由当前 v6 源、多语言、视觉资产、专业电影人、视觉压力测试与平台刷新层使用的证据。它是日期化的工作层，而非对平台访问、价格、限制或地区可用性的永久保证。

## 来源优先级

1. 官方字节跳动 Seed 页面与发布文章。
2. 官方火山引擎或 BytePlus ModelArk 文档。
3. 官方或合作方工作流文档，如 ComfyUI 合作方节点。
4. 提供方发布的学术/模型卡材料。
5. 专业电影、后期、调色、字幕、音频与交付标准。
6. 用于仓库结构的智能体技能打包文档。
7. 社区提示词指南、论坛、提示词语料与包装器文档。

## 已确认的官方信号

- 字节跳动 Seed 将 Seedance 2.0 描述为支持文本、图像、音频和视频输入的统一多模态音视频生成模型。
- 官方发布文章称用户可提供最多 9 张图像、3 段视频片段、3 段音频片段，外加自然语言指令。
- 官方材料强调参考用于构图、摄影机语言、动作节奏、特效与声音特征。
- 官方材料将视频延长和剪辑描述为核心能力，而非仅新的文本到视频生成。
- 火山引擎的 Seedance 2.0 教程在 2026-05-29 被观察到有更新，并列出 `doubao-seedance-2-0-260128` 与 `doubao-seedance-2-0-fast-260128`。
- 火山引擎的 5 月 29 日视频生成教程现在是重新检查首帧与尾帧角色、返回尾帧、网络搜索工具与输入组合规则的活跃第一手平台。
- 火山引擎的 Seedance 2.0 提示词指南在 2026-05-15 被观察到有更新，并强化了角色绑定的多模态参考提示词。
- 火山引擎的 5 月 28 日价格页面仅可在附源日期、平台、模型、货币与重新检查注意事项的情况下引用。BytePlus JavaScript 渲染的页面在引用价格前仍需要实时核验。
- Runway 记录了一个单独的官方 Seedance 2 平台，使用模型 ID `seedance2`、5–15 秒时长、托管的 `runway://` 上传与音频参考组合规则。
- Runway MCP 于 2026-05-27 作为智能体连接器平台推出。将其视作 Runway 访问/工作流证据，而非字节跳动 API 能力声明。
- 真实人物肖像或人声工作流需要授权、平台支持与平台特定核验。
- 字节跳动自己的发布材料列出剩余弱点：细节稳定性、超写实、动态活力、多主体一致性、文本渲染、复杂剪辑与偶发音频失真。
- OpenAI 当前的 Codex Agent Skills 文档将技能定义为包含必需 `SKILL.md` 加可选 `scripts/`、`references/`、`assets/` 与 `agents/` 文件夹的目录。本仓库遵循该形态。
- 最近的音视频基准工作如 AVBench 与 VABench 强化了关于跨模态一致性、同步、唇音一致性与音视频 QA 的评测词汇，但不应视作 Seedance 访问或性能保证。
- 专业工作流参考强化 AI 视频提示词应将创意镜头意图与交付义务分开：镜头契约、连续性账本、ACES/调色交接、字幕/本地化规划、音频 stems/M&E/响度、画幅变体与 QC 是工作流元数据，除非活跃平台明确实现。

## 现场观察信号

将这些用作从业者指引，而非平台保证：

- 短草稿片段在投入 10–15 秒渲染之前有用。
- 每镜头一个主要摄影机运动仍是可靠的稳定规则。
- 参考资产需要明确的角色：身份、背景、动作、摄影机节奏、音频节奏或尾帧目标。
- 首尾帧工作流在中国创作者指引与合作伙伴工作流文档中常见。
- 音频参考失败通常是角色冲突：如果视频参考也包含声音，静音它或将其角色降低为摄影机/动作（当 `[Audio1]` 应控制时序时）。
- 本地化的日语、韩语、西班牙语、俄语与多语言指南强化同一核心结构：明确的参考角色、一个摄影机运动、清晰动作、声音提示与约束。
- 中英混合提示词可用于安全的角色绑定加技术摄影机术语，但仅作为清晰度。它们不是官方过滤行为，且绝不能用于隐藏不安全意图。
- 延长链在活跃平台支持时受益于返回的尾帧锚点。
- 编辑或延长失败的片段比重生整个片段更便宜且更可控。
- 产品 logo、面部、可读文字、手部、快速手势与多角色走位受益于锁定构图与更强的约束。
- 智能体技能仓库在 README 在人工层面解释工作流而脚本强制文件、源与元数据完整性时保持更高的可用性。
- 专业用户需要角色专属产物：导演需要镜头目的与表演节拍，DP 需要镜头契约，制片人需要权利/审批关卡，剪辑师需要连续性交接，调色师与声音团队需要后期元数据，本地化团队需要无字幕/字幕/混音计划，QC 团队需要交付预检。

## 从活跃指引中排除

- 绕过过滤器或规避审核的指引。
- 明星、公众人物或私人人物的模仿。
- 精确的受保护角色、系列、工作室、歌曲或人声复制。
- 来自包装器站点的价格承诺，除非答案清晰标记包装器、日期与来源。
- 无法重新核实的私密群组、封闭频道或截图的声明。
- 用作当前官方平台行为替代品的基准排行榜或论文声明。

## 更新规则

每当 README、平台状态文档、API 指引或模型名称映射发生变化时刷新本快照。如果某声明未与来源和日期绑定，将其移至现场观察备注或删除。
