# 事件密度

使用本参考来决定一段故事应该归属于几次生成。

## 密度规则

一次生成通常应承载一个可见的节拍以及一个改变的端点。长背景、多地点、多主要动作、密集对白和未来收尾都属于序列规划，而非当前提示词。

## 节拍分桶

`already_happened`（已发生）：不要重演。

`this_clip_only`（仅本片段）：当前提示词可以执行。

`reserved_for_later`（保留至后续）：暂不展示。

`do_not_show_yet`（暂不展示）：即使能解释动机，也予以排除。

## 范围防火墙

故事上下文可以启发动机、表演、氛围与节奏。它不能导致当前片段执行未来事件、揭示未来信息、解决后续问题，或跳过物理交接状态。

## 拆分触发

当请求包含多个已完成动作、跨越多地的旅程、多轮对白、复杂物理接触、产品验证加主角包框镜头，或故事长度超出已验证活跃平台时长时，予以拆分。
