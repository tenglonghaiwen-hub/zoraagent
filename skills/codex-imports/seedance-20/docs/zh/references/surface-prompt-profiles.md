# 平台提示词档案

使用本参考以保持平台行为平台特定。不要把时长、提示词长度、参考数量、标签语法、剪辑支持、延长支持、音频行为、地区、价格或授权要求硬编码为通用 Seedance 事实。

## 档案字段

对活跃平台，解析：

- 精确的参考标签约定；
- 已验证的时长范围；
- 提示词预算；
- 支持的参考角色；
- 时间轴语法；
- 剪辑或延长可用性；
- 音频行为；
- 已知约束；
- 来源与核实日期。

若平台未知，声明档案为保守，并避免不支持的数字。

## 保守通用档案

仅当无已知平台时使用：

- 一次规划一条紧凑的生成大小片段；
- 保持提示词简明；
- 精确保留用户提供的标签；
- 避免断言原生延长、提示词限制或参考数量；
- 在续拍前请求实际片段或尾帧；
- 偏好角色绑定参考，而非不支持的功能声明。

## 易变声明规则

对于当前模型名称、价格、上传限制、参考数量、地区、端点名称或授权要求，加载源控参考，并在做出操作声明前使用带日期的主要来源进行核实。
