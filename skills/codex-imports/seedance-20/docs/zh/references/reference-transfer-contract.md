# 参考传递契约

当序列中出现图像、视频、音频、前序片段、尾帧或界面标签时，使用本参考。

## 精确标签规则

精确保留每个用户提供的参考标签。绝不创造、规范化、翻译、重新格式化、重新编号、修正空格或改变大小写形式，例如 `@Image1`、`@Image 1`、`[Image1]`、`[Video 1]` 或界面提供的等价形式。

## 角色分离

为每个参考分配一个主要角色：

- 图像：身份、产品、姿态、服装、环境、首帧或尾帧；
- 视频：源片段、动作、摄影机、时序、走位或连续性来源；
- 音频：节奏、环境声、音乐相位、节奏、表达语气或活跃对白来源；
- 尾帧：观察状态或目标端点。

声明哪些传递、哪些不应传递。当身份、动作、摄影机、环境和音频角色互相渗入时，R2V 与续拍工作就会失败。

## 连续性来源 vs 动作参考

规范身份参考控制不可变的身份。一个已接受的前序片段或尾帧控制瞬时开场状态。供体视频仅在显式允许时控制动作或摄影机。不要让动作参考覆盖角色身份、服装、产品几何或已接受状态。

## 多主体选择器

当参考包含多个主体时，按位置、标签、角色或可见特征识别预期主体。在用户未指明时，不要假设中央或最大主体就是正确的。

## 传递与忽略条款

每个角色绑定的参考应表达为：

`[ReferenceTag] controls [role] only; ignore [identity/environment/logo/audio/camera/motion] from that reference.`

对于受保护身份、人声、品牌、logo 或表演的传递，仅使用自有、已授权、公共领域、素材库、自录或明确获授权的参考。
