# 变更日志 — seedance-20

本项目的所有重要变更均记录于此。

当前活动发布：**6.3.0**。以下更早条目作为发布历史保留，而非活动版本指引。

## 未发布

_尚无未发布变更。_

## [6.3.0] — 2026-06-29

### 新增

- 将深度音频架构研究纳入 `references/audio-guide.md`、`seedance-audio` 以及每种语言的 `vocab/*.md`：一个"音频实际如何工作"的推理模型（音视频联合生成、声音从画面推断、语音与发音耦合、某些平台唇形同步默认关闭、概率可靠性、每种语言强度不均）——全部标注为现场观察且平台特定，绝非官方。
- 新增现场观察的每语言对白承载力表（英语约 16–20 个可靠同步词 / ~15 秒，俄语约 10–15 个且较弱，普通话最强，日语/韩语较弱且测试不足），以及"声学预算 vs 可靠同步预算"的区分和跨语言单元"一句短句 ≈ 一口气"。
- 记录语音参考唇形同步路径：在接受人声参考的平台上，附加已授权人声可直接驱动唇形同步（模型同步到该人声而非合成语音）——这是非英语对白最可靠的现场报告路径，纠正了此前"音频参考 = 仅节奏/氛围"的描述。视作权利敏感场景，未明确时通过版权流程路由。
- 新增现场观察的内联音频标签对话模式与即梦唇形同步默认关闭说明，以及评测用例 `audio_reference_lipsync_non_english`。

### 变更

- 将活动元数据、README 徽章（122 个评测用例）、评测/验证器预期、清单、就绪状态、范例与翻译条目升级到 v6.3.0。

## [6.2.0] — 2026-06-28

### 新增

- 新增 `scripts/eval_run.py`，一个模型在回路中的评测工具：它从真实技能内容（根 `SKILL.md`、用例期望的子技能以及任何 `state_fixture`）构建响应者上下文，获取对每个用例提示词的响应，然后让评判模型根据 [`references/eval-rubric.md`](../../references/eval-rubric.md)（0–3 旧版 / 0–4 序列量表以及文档化的发布阈值）对照用例自身断言对响应评分。离线的 `--self-test` 连线检查在 CI 中运行；实时评分通过是存在于离线 CI 之外的质量关卡，记录于 `evals/eval-run-ledger.md`。
- 新增六个导演引擎评测用例（揭示 vs 告别的不同设置、模式断裂标记转折、以姿态作为表演、通过矛盾表达潜台词、光比服务于情感、拒绝无动机技法），让 v6.1.0 旗舰功能获得对等覆盖。

### 变更

- 去模板化全部 47 个序列评测用例：每个用例现在都带有具体场景提示词和 2–4 条用例专属断言，命名其 id 所承诺的行为，替代占位符"V6 check: ..."提示词和相同的三条泛化断言。结构字段（`forbidden_behaviors`、`expected_sequence_relation`、`critical` 等）保留，因此 `sequence_eval_check` 仍然有效。
- 拆分 454 行导演引擎以符合渐进披露原则：33 个类型完整范例库迁移到 `references/directing-engine-genre-library.md`，按需通过类型/范例路径加载，使常驻的导演步骤不再拉取整个库（推理核心保持约 157 行）。
- 重写 `references/progressive-disclosure.md`，描述真实的文件集、轻重参考加载、导演引擎拆分、类型内容归属图与新鲜度规则。
- 为 `seedance-continuation`（唯一缺少 Intent 段的子技能）新增 `## Intent` 段。
- 新增三道 CI 关卡：每个子技能必须携带 `## Intent`；时效关键的平台参考必须保持在 `api-status.md` 的 `last_verified` 起 30 天内；`progressive-disclosure.md` 必须记录导演引擎的重参考。
- 将活动发布元数据、README 徽章（121 个评测用例，58 个参考）、评测/验证器预期、清单、就绪文档、范例和翻译条目升级到 v6.2.0。

## [6.1.1] — 2026-06-28

### 变更

- 为根技能运行回路新增**快速通道**：来自非专家、单一独立片段、无 IP/安全标记且无平台事实问题的请求，现可直接路由到 `seedance-interview-short` → `seedance-prompt-short`，源关卡、专业关卡、能力图、分配模型和导演引擎均改为按需加载而非强制加载。这修复了技能自身在最常见场景下对意图优先 / 渐进披露原则的自伤式违反。
- 将导演引擎改为按需加载而非常驻：根导演步骤与完整访谈现在从记忆中内联应用"一个句子意图"连贯规则，仅在场景需要差异化处理、需要一种声音贯穿多片段、或设置确实不清晰时加载 `[ref:directing-engine]`。
- 对普通单片段想法延后序列/续拍访谈问题（第 6–9 问）：第 1–5 问是单片段核心；只有当想法已经构成长故事或用户提示是系列、第二部分、续拍、变长时，才提出第 6–9 问。
- 新增评测用例 `beginner_fast_lane_single_clip`；将活动元数据、README 徽章、评测/验证器预期、清单和就绪文档升级到 v6.1.1（115 个评测用例）。

## [6.1.0] — 2026-06-22

### 新增

- 新增 `references/directing-engine.md`：位于摄影机、灯光、动作和角色查找表之上的导演推理层。它读取一场戏的戏剧功能（功能、转折、视角、权力、潜台词），命名一个意图，并衍生出一套统一的设置，使摄影机、镜头、灯光、走位、表演和声音都强化该意图，而非堆砌泛化的"电影感"描述词。
- 新增导演声音模型，包含六个 IP 安全的职能风格原型，让项目保持一致的导演手法，外加贯穿相连片段的长篇外观脊柱，逐步推进尺度、运动、光线与声音，并标记在故事转折处打破该模式的单一片段。
- 新增表演指导，将情绪转换为每个节拍唯一可见的真实姿态，通过矛盾演绎潜台词，并以连贯性测试拒绝无动机的技法。
- 新增导演引擎中 35 条类型的完整范例库，涵盖商业（产品、美妆、美食、汽车、高端时尚、T 台、房地产、口播推介）、表演与能量（MV、体育、健身、旅行）、叙事与类型电影（亲密对话、双人对手戏、短剧、浪漫、恐怖、黑色、动作、奇幻、科幻、怀旧）、动画与风格化（2D 动画、3D/CG、定格动画、儿童）、观察与真实（UGC、纪录片访谈、自然/野生动物、宠物、建立镜头）以及技术（变形/VFX、延时）。每条都是完整的读取、意图、声音、设置、表演和编译提示词推导，呈现独特的导演声音。
- 新增两条评测用例：`directing_scene_coherence` 与 `directorial_voice_across_sequence`。

### 变更

- 将导演引擎接入根技能与 `seedance-interview`、`seedance-interview-short`、`seedance-prompt`、`seedance-camera`、`seedance-lighting`、`seedance-motion`、`seedance-characters`、`seedance-sequence` 和 `seedance-continuation` 的运行回路和加载地图，让场景导演、表演和单一导演声音从访谈贯穿到提示词再到长篇续拍。为序列片段卡片新增 `arc_position` 字段。
- 将活动发布元数据、README 徽章、参考库、评测元数据和验证器预期升级到 v6.1.0（28 个子技能、57 个参考、114 个评测用例）。

### 从 v6.0.x 维护继承

- 为 EvoLink、OpenRouter、Kie.ai、PiAPI、LaoZhang、Runware、ModelsLab、AI/ML API、MuAPI、SeeGen 和 Segmind 引入源控的提供商/路由覆盖，同时保持它们被标注为第三方或路由平台而非官方 ByteDance 行为。
- 加入面向中国市场的提供商检索边界，将官方 ByteDance/火山引擎/BytePlus/豆包/即梦/剪映平台与工作流托管方、中文博客和商业伙伴新闻区分开——后者在缺少提供方自有文档时不应被视为公开 API 提供商。
- 引入官方源控的 Seedance 2.0 Mini 命名，包括火山引擎的 `doubao-seedance-2-0-mini-260615` 与 BytePlus 的 `dreamina-seedance-2-0-mini-260615` 平台 ID，以及 "Seedance V2 Mini" 的简写规则。
- 恢复 Runway Seedance 专属 API 指南作为与稳定 Models、API Changelog、Inputs 和帮助链接并列的主要来源，并对原始 HTTP 状态不一致添加检查器注意事项。
