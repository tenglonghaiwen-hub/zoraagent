# seedance-copyright

在最终确定涉及受保护 IP、指名品牌、公众人物、私人人物、人声、logo、歌曲、工作室、精确场景或相似角色请求的提示词前使用此参考。目标不是淡化想法；目标是保留创意功能，使用原创、授权与更安全的制作语言。

## 意图

用户指向受保护的作品并非试图偷窃 —— 他们正在向你展示他们所爱的事物中存在的最清晰范例。工作是找到爱由什么构成，并将其作为安全属于他们的东西还回来。在同一动作中保护权利人与用户的心。

## 改写原则

保留场景功能、类型、情绪、摄影机逻辑、情绪节拍与制作意图。用原创原型、原创服装逻辑、原创世界细节与描述性风格层取代受保护身份。

| 风险 | 替换为 |
|---|---|
| 指名角色或系列 | 原创原型、类型功能与非相同服装语言 |
| 工作室或在世创作者风格 | 媒介、质感、调色板、构图、线条质量与动作节奏 |
| 明星或私人 | 原创表演描述或授权参考工作流 |
| 品牌 logo | 通用产品标志、空白标签或用户自有品牌（若明确授权） |
| 歌曲、人声或表演 | 节奏、能量、配器、情绪或新创作的声音方向 |
| 精确场景复刻 | 具有相似叙事功能与不同设置/走位的原创场景 |

## 授权关卡

如果用户明确拥有品牌、资产或肖像权利，保留授权元素但仍用显式约束保持它们。如果授权不清晰，询问简短确认或提供安全的原创改写。不要从上传的图像、歌曲或视频假设权利。

对真实人脸、肖像或人声，分离三个问题：活跃平台是否支持输入、用户是否有授权、提示词是否避免在无同意下模仿公众人物或私人。一些平台使用经验证的虚拟肖像资产或授权流程；不要将它们折叠为通用允许或拒绝规则。

## 安全替换范例

代替一名指名超级英雄穿越可识别的系列城市，写：`original masked rooftop courier in a red weatherproof jacket leaps between rain-slick buildings, low handheld tracking camera, blue police lights far below, no logos or franchise symbols`。

## 输出契约

返回风险类别、修改的内容、安全的替换提示词、授权要求与任何残留约束。
