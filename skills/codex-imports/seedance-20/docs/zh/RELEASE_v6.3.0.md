# Seedance 2.0 Skill OS — v6.3.0

一个模块化的智能体技能操作系统，用于执导字节跳动 **Seedance 2.0** 视频。它将模糊的想法转化为生产就绪的提示词，**像电影导演一样执导每一场戏**，保持平台事实日期化，改写不安全的 IP，并规划跨越多个片段的长篇故事 —— 为英语、中文、日本語和 한국어 提供母语读者路径。

## v6.3.0 的新内容 —— 诚实地完成音频

对 Seedance 2.0 **原生音频与对白**进行深度、批判性的研究，已纳入技能中并标注为**现场观察 / 平台特定 —— 绝非官方**。

- **最重要的修正：** 音频参考不再被低估为"仅节奏/氛围"。在接受人声参考的平台上，**附加的已授权人声可以直接驱动唇形同步** —— 模型同步到你的人声而非合成语音。这是**非英语对白**最可靠的现场报告路径，并被视为权利敏感场景（自有/已授权/已清白的人声，未明确时通过版权流程路由）。
- **一个架构推理模型**（"音频实际如何工作"）：音频和视频是联合生成的；模型**从画面推断声音**（"泛化默认音频"的根本原因 —— 通过命名确切声音来覆盖）；语音和发音耦合（无声唇形同步不可靠）；唇形同步**在某些平台上默认关闭**；可靠性是概率性的；每种语言的强度不均。
- **现场观察的每语言对白承载力表**，含*声学预算 vs 可靠同步预算*区分与跨语言单元"一句短句 ≈ 一口气"：英语约 16–20 个可靠词 / ~15 秒，俄语约 10–15 且较弱，普通话最强，日语/韩语较弱 —— **韩语被明确标注为测试不足而非假设**。
- 跨所有六个词汇文件的每语言对白注意事项、内联音频标签模式，以及带权利意识的评测（`audio_reference_lipsync_non_english`）。

## v6 系列回顾

- **导演引擎** —— 读取场景的戏剧功能，命名一个意图，让摄影机、灯光、走位、表演和声音服务于它，贯穿故事保持一种导演声音；33 个类型完整范例库按需加载。
- **有状态长篇** —— 全局规划，本地生成：相连片段，严格从已接受画面续拍。
- **初学者快速通道** —— 常见的单片段想法跳过完整关卡回路。
- **真实评测工具** —— 回路中的模型评分器根据每个用例的断言对技能*输出*评分；质量标准是被衡量而非被断言的。
- **多语言 + 安全** —— zh/ja/ko 母语文档和范例，zh/ja/ko/es/ru 电影词汇，IP 安全改写，源日期化的平台事实。
