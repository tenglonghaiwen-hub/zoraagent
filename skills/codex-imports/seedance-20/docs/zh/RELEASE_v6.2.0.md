# Seedance 2.0 Skill OS — v6.2.0

用于执导字节跳动 **Seedance 2.0** 视频的模块化智能体技能操作系统。它将模糊想法转化为生产就绪的提示词，**像电影导演一样执导每一场戏**，保持平台事实日期化，改写不安全的 IP，并规划跨越多个片段的长篇故事 —— 为英语、**中文**、日本語、한국语 提供母语读者路径。

## 自 v5.3.0 以来的头条

**导演引擎** —— 读取场景的戏剧功能（转折、视角、权力、潜台词），命名一个意图，并让摄影机、镜头、灯光、走位、表演与声音都服务于它，贯穿整个故事保持一致的导演声音。随附一个 33 个类型的完整范例库，按需加载。

**有状态长篇** —— 全局规划，本地生成：将故事划分为相连片段，仅编译当前片段，并严格从*已接受画面*继续，永不凭空发明状态。

**多语言与安全** —— 中文、日文和韩文的母语文档和示例子技能；zh/ja/ko/es/ru 的电影词汇；IP 安全改写；误报过滤修复；无猜测的 API、价格或模型 ID 声明。

## v6.2.0 中的新内容

- **初学者快速通道** —— 常见的单片段想法跳过完整关卡回路，直接路由到快速简报与紧凑提示词；沉重参考仅在需要时加载。
- **真实评测工具** —— 一个模型在回路中的评分器（`scripts/eval_run.py`）根据用例断言使用 `references/eval-rubric.md` 对技能*输出*评分。质量标准现在是**被衡量而非被断言**。全部 47 个样板序列用例被重写为具体场景；总计 **121 个评测用例**。
- **架构硬化** —— 为渐进披露合规拆分导演引擎，并新增三道 CI 关卡：每个子技能携带一个 Intent 段；时效关键平台参考保持与 `api-status.md` 当前一致；披露计划保持诚实。
- **演进的编辑报头** —— 书法 wordmark、等宽眉签引导线、琥珀色菱形装饰，跨明暗主题保持主题感知。

## 质量标准

28 个子技能、58 个参考、121 个评测用例。11 个确定性 CI 验证器加上每次 push 上运行的单元测试，使用回路中的模型工具作为语义质量关卡。
