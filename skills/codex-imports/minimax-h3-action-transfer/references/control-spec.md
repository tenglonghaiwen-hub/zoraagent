# 动作迁移控制规范

## 素材职责与优先级

- 参考视频：唯一负责动作、表情、视线、口型动作、头部转动、姿态、位置与大小、发丝运动规律、衣料动力学、道具交互、镜头和剪辑。
- 人物图：唯一负责被确认范围内的人物身份、五官、发型、体型和服装。人物五官必须作为强约束展开为可观察特征，不能只写“保持一致”。
- 服装图：只负责服装版型、层次、颜色、材质、配件和穿着关系；优先级高于人物全身图中的服装。
- 场景图：按用户确认负责环境结构、材质、天气、色彩或光源；不得默认承担未确认的职责。
- 道具图：负责新道具外形、比例、材质、部件和功能；动作视频仍负责交互时序，但交互必须适配新道具。
- 音频：按用户选择负责原信号复用、节拍、声音风格、音色或对白，不能含糊混用。

## 人物与服装替换

开启人物替换时，逐帧清除原人物脸、头皮、头发、耳朵、颈部、身体、四肢、服装和鞋的残留。覆盖发丝透明边缘、运动模糊边缘、手指缝、腿间空隙、衣物开口及人物与道具交界。跨镜头和跨片段锁定脸型、五官比例、发际线、发量、发长、体型和服装结构。

只有脸部参考时只替换五官长相，不自行改变发型、体型或服装。全身或多视角人物图可以控制身份、体型与其可见服装；独立服装图覆盖人物图中的服装信息。

## 发丝动力学

开启发丝 1:1 迁移时，迁移参考视频中可观察的风向、阵风开始/增强/减弱时点、主发束方向与幅度、头部运动产生的惯性滞后、扫脸时点、自碰撞和阻尼回落。人物图决定发色、发际线、长度、密度和基础发型。

发根固定在头皮，主发束从根到梢连续弯曲，发梢摆幅通常大于发根；细碎发丝具有合理的幅度差和相位差。发丝与额头、眼睛、脸颊、嘴唇、耳朵、肩部、衣领和道具保持正确遮挡、碰撞与滑动。运动模糊宽度随速度变化，禁止硬板假发、液体感、烟雾感、复制残影、瞬移、断裂、融化、黏脸或边缘闪烁。

## 场景和光源决策

场景替换关闭时，保留原视频场景和默认原视频光源。场景替换开启时，逐帧移除原背景、前景、天空、地面、倒影和运动模糊中的原场景颜色；从场景图重建同一个三维空间，跨镜头稳定建筑坐标、路缘、地平线、透视消失点、视差、遮挡和景深。

场景替换时必须询问光源来源：

- 选择原视频光源：新人物、新道具和新场景全部适配原视频主光、环境光和氛围光。
- 选择场景图光源：人物、道具和场景全部适配场景图的主光方向、软硬、色温、曝光和反射。
- 未上传场景图：默认原视频场景和光源。

检测原人物和原场景光线是否不一致，并识别闪光灯、手电筒、路灯、车灯、屏幕光、霓虹等第三方光源。向用户说明其方向、色温、衰减、作用范围与对象，询问保留、删除或改造，不能擅自解释为环境主光。

## 强制同层融合

人物、发丝、衣料、道具和场景必须在同一个三维空间、同一渲染层、同一相机曝光与色彩变换中共同成像。统一：

- 透视、尺寸、地面接触和受力。
- 主光方向、软硬、色温、曝光和阴影。
- 环境反射、距离衰减、氛围光和第三方光源。
- 前后遮挡、景深、焦点、颗粒、压缩质感和运动模糊。
- 发丝扫脸时的细微投影、鞋底接触阴影、道具对人物和环境的反射。

禁止独立前景贴背景、白边/黑边/色边、光晕、局部曝光断层、脚底空隙、人物漂浮、前后景不同帧率或背景二维贴片感。

## 道具与手部交互

默认保留原道具及原交互。上传新道具图时识别其尺寸、重量、质心、握持位置、开合方式和功能，把原交互改造成适配新道具的动作，同时保持镜头节奏。明确删除道具时，删除原道具及其残影，把握持、按压、翻页、饮用等动作改为空手自然动作或用户指定的新动作；不得留下悬空手势。

## 口型、音频与水印

检测说话场景并保留口型动作。复用原音轨时保持口型、呼吸、停顿和声画卡点；关闭原音轨时仍保留自然口部动作，除非用户要求静默闭口。更换对白或音色时按新声音重做口型和表情节奏。

默认删除原水印和水印残影。其他准确文字建立白名单，未列入白名单的新增文字、Logo 和乱码不得出现。

## 提示词结构

每段提示词必须先写素材索引，再写成片指令。索引逐项使用与上传顺序完全一致的标签，例如：

```text
素材索引：
<视频1｜第一段动作视频>：锁定动作、表情、视线、姿态、人物位置、机位、运镜、切点和节奏；不得决定人物长相或新场景外观。
<图1｜人物参考图>：锁定人物身份、五官、发型、体型和已确认的服装；不得改变视频1的动作和镜头。
<图2｜场景参考图>：只负责环境结构、材质、天气，以及用户选择时的光源；不得覆盖人物身份。
```

省略不存在的素材并连续编号，不保留空槽。索引只包含编号、简短用途标签、锁定项、负责项和不得影响项；不得写完整文件名、扩展名或本地路径。同类素材难以区分时使用“人物正面参考”“人物侧面参考”“道具A”等短标签。索引后明确冲突优先级；正文继续使用 `<视频1>`、`<图1>` 等编号标签，不得退化为含糊的“参考图”或让不同素材竞争同一身份或光源。

索引后至少包含：成片定义、人物/服装锁定、场景与光源、同层融合、发丝/衣料、相对时间轴、镜头动作、道具/口型/声音和针对该任务的失败约束。
