# 问询与模块开关

## 只读素材检查

逐个打开图片并抽取视频关键帧，不得依赖文件名。至少确认：

- 视频容器、视频/音频编码、分辨率、画幅、帧率、精确时长和音轨。
- 镜头数量、自然切点、每镜动作、表情、视线、头部转动、姿态、人物位置与大小、景别、机位、运镜、构图、节奏和转场。
- 可见口型与说话时段、道具、手部接触、遮挡和动作因果。
- 发型、发根、主发束、细碎发丝、风向、阵风时点、摆幅、惯性、回落与自碰撞。
- 场景几何、地平线、透视、天气、主光方向与软硬、色温、环境反射、氛围光和第三方光源。
- 原人物和原场景的光线是否一致；是否存在闪光灯、手电筒、路灯、车灯、屏幕光、霓虹或其他局部光源。

## 确认前必须展示

向用户简短展示：

1. 已查明的素材事实与不确定项。
2. 准备保留、替换、删除和新增的内容。
3. 逐项上传顺序：明确写出视频1、图1、图2、音频1分别上传哪类素材，并用简短用途标签区分；不写完整文件名或路径，也不得只说“上传参考素材”。
4. 每份图片、视频、音频的唯一主责、锁定项、禁止影响项和冲突优先级。
5. 光源选择、第三方光源处理和同层融合策略。
6. 分段边界、各段源时长、H3 目标时长、任何补帧/延续/轻微变速及最终时长恢复方式。
7. 将创建的确切文件路径、数量和影响；明确原文件不变。

随后要求一次明确确认。确认前允许在 `work` 中抽帧、裁剪、放大、标注和生成联系表；没有确认不得写最终提示词、切割正式参考视频或创建正式 `outputs` 副本。

## 模块状态

| 模块 | 默认状态 | 规则 |
|---|---|---|
| 人物身份替换 | 默认开启 | 上传人物图时启用；无人物参考时要求上传或让用户关闭。人物五官是强约束。 |
| 服装替换 | 条件默认 | 全身图或多视角人物图默认采用其中服装；独立服装图的服装优先；只有脸部参考时仅换五官，不改发型、体型和服装。 |
| 场景完全替换 | 每次询问 | 上传场景图不自动等于替换；确认它负责场景替换、仅光线或仅色彩。未上传场景图默认保留原场景。 |
| 光源角度与色温匹配 | 默认开启 | 场景替换时询问使用原视频光源还是场景图光源；未上传场景图默认原视频光源。 |
| 第三方光源 | 每次询问 | 检测后列出来源、方向、范围和作用对象，询问保留、删除或改造。 |
| 强制人物场景同层融合 | 默认开启 | 不允许关闭到产生贴图感的程度。 |
| 发丝动态 1:1 迁移 | 每次询问 | 开启时迁移风向、幅度、阵风时点、惯性、自碰撞和回落，不迁移原发色或原人物身份。 |
| 衣料和配饰动力学 | 默认开启 | 保留与动作、风力和重力一致的摆动、碰撞和阻尼。 |
| 动作与表演 1:1 迁移 | 默认开启 | 包括表情、视线、头部转动、姿态、位置和大小。 |
| 机位、构图和运镜 | 默认开启 | 逐镜锁定景别、机位、焦段感、路径、速度和手持幅度。 |
| 切点与剪辑节奏 | 默认开启 | 保留自然切点、转场触发和声画节奏。 |
| 道具保留 | 默认开启 | 无新道具图和删除要求时保留。上传新道具图时默认替换并重做握持、重量和功能交互；明确删除时改为空手或合理新动作。 |
| 原音轨复用 | 默认开启 | 用户可以关闭；开启时保留声画卡点。 |
| 口型动作 | 条件默认 | 检测到说话时保留自然口型；更换声音或台词时同步调整口型、停顿、呼吸和表情。 |
| 原水印和文字删除 | 默认开启 | 水印是强约束删除项；其他文字按用户白名单处理。 |
| 自动检测切点 | 默认开启 | 实际分析视频，不凭估计。 |
| 自动分段 | 默认开启 | 参考副本和脚本建议生成时长最低 2 秒；即使官方标注生成最低 4 秒，也跳过该限制并继续使用脚本的 2 秒下限。 |
| 自动制作参考视频副本 | 默认开启 | 获批后只写 `outputs`，不覆盖文件。 |
| 多段连续性锁定 | 默认开启 | 人物、服装、发型、场景坐标、光源、材质与色调跨段一致。 |
| 自动生成多份 H3 提示词 | 默认开启 | 每个视频副本一份，素材编号和相对时间轴对应。 |
| H3 规则校验 | 默认开启 | 同时做机械限制与语义覆盖检查。 |
| 失败诊断与二次强化 | 默认开启 | 只根据实际输出故障强化相关约束，不重写已正确部分。 |
| 调速适配整数秒 | 默认开启 | 使用最小改动，保护动作、口型、音频和发丝动力学。 |
| 最终精确裁切与拼接 | 默认开启 | H3 输出后恢复源片段帧数，最终总时长与原视频一致。 |

用户当次明确选择始终覆盖默认状态。
