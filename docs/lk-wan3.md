# 万相 3.0（强哥AI）

接口文档：https://qiangge888.com/apidoc#model/wan3.0

- 独立模型 ID：`wan3.0`；供应商 `custom`，服务地址 `https://api.lk888.ai`。
- 模板 `lk-wan3`；提交 `POST /v1/media/generate`，查询 `GET /v1/media/status?task_id={task_id}`。
- 后台默认标准版 `wanVersion: "standard"`。可在能力 JSON 改为 `"prime"`；修改时应同步调整按次积分价格。可选 `wanAudio` 和 `wanPromptExtend` 为布尔值。
- 分辨率 `480P`、`720P`、`1080P`；时长 2–30 秒。客户端以 `-1` 表示智能时长，提交时转换为 `auto`。
- 纯文字、首帧、首尾帧和参考生成；最多 10 张参考图、5 段参考视频、5 段参考音频。上游参考视频需为公网直链。Zora 可在正式提交万相任务时，将本地 MP4（单个不超过 24 MiB，合计不超过 32 MiB）暂存到专用私有 R2 桶，向上游提供 48 小时有效的签名读取链接。预览不上传文件；未取得任务回执时禁止换请求编号重提。文档直链和网页链接只能选择其一，客户端可在万相创作栏输入。本地文档上传尚未接入，需先取得公网直链。
- 专用桶为 `zora-wan-reference-media`，对象前缀 `zora/wan-reference/`。签名链接过期后不可读取，但对象不会自动删除；开通前需考虑持续存储费用，并另行确定经用户确认的清理方式。桶未创建或未绑定时，本地参考视频提交会失败并退还本次预留积分。
- 参考视频总时长加输出时长不超过 30 秒；网址素材的真实时长由上游校验。智能时长按上游规则先按 30 秒计费，最终由上游结算。Zora 当前为后台可改的**按次积分价**，不会根据上游实际秒数自动调整用户积分，因此启用前需按可接受的最高成本定价。
- 新模型默认关闭且积分单价 0 为占位。管理员需先填写按次积分单价，再开放给客户端。现有多元视频模型及 MiniMax H3 不变。

任务提交先保存账号所属回执，重复请求编号只恢复原回执，不重复提交。轮询按 `is_final`、`state` 判定，失败时只退一次积分。未进行任何付费视频生成验证。

测试：`node --test tests/lk-wan3.test.mjs tests/lk-minimax-h3.test.mjs tests/h3-operations.test.mjs`
