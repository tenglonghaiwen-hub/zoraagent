# 剪映桌面控制

> 维护说明（2026-09-15）：当前能力、入口与限制见 [当前实现状态](CURRENT-STATUS.md)。本文中的版本验收数字、当时状态和后续计划保留为历史记录；涉及 RunningHub 的接入计划已取消，相关接口现已移除。

新增 Agent 工具 desktop_jianying，提供窗口枚举、启动、读取可访问界面、点击、文字输入和有限快捷键。工具不是任意 PowerShell/终端入口。剪映之外的窗口不在本轮允许范围内。

桌面端随机端口与随机令牌保护本机桥，拒绝 Origin 请求；读取操作不修改窗口，启动、点击、输入与按键逐次弹出用户确认。取消时不执行。窗口句柄、进程归属与前台焦点必须校验。

读取依赖 Windows UI Automation。剪映自绘的时间线、素材画面或某些按钮可能不暴露可访问元素；不能猜测不可见坐标。该版本未实现屏幕图像识别、拖拽时间线和完整剪辑流程，不能宣称能自动完成所有剪映项目。

桌面桥加载需要退出重开客户端；后端工具目录加载需要重启后端。执行不依赖 Docker，不将第三方模型密钥交给桌面控制脚本。

验证：94 项测试通过，驱动另外 4 项测试通过；实际只读枚举确认安装位置 D:/JianyingPro/JianyingPro.exe，目前窗口列表为空。后端已重启。没有启动、点击或修改用户的剪映工程，完整导入—剪辑—导出流程尚未验收。
