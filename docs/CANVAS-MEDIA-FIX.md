# 画布媒体生成提交修复（2026-09-19）

画布此前在提交前把预分配 UUID 写入 genBatchId，公共生成函数据此进入查询分支，未提交生成请求便查询不存在的任务。现在使用独立 genRequestId 预留编号，首次执行提交生成，收到回执后再查询。

云端模式不再要求仅本地具备的持久任务能力接口；收到上游任务编号后，通过云端 /api/tasks 接口查询。请求继续携带画幅、分辨率、时长与参考素材。本地模式保留持久任务恢复检查。

异常时也保存任务状态。云端提交回执丢失会明确提示核对记录，并阻止该画布节点直接重复提交；目前没有按本地 UUID 找回云端任务的能力。未进行付费生成验收，不保证上游模型输出画幅或可用性。

新增回归测试覆盖首次提交、云端提交与查询、云端回执丢失。客户端资源版本更新以避免缓存旧代码。
