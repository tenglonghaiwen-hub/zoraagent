# studio131：选项记忆与自动下载

> 维护说明（2026-09-15）：当前能力、入口与限制见 [当前实现状态](CURRENT-STATUS.md)。本文中的版本验收数字、当时状态和后续计划保留为历史记录；涉及 RunningHub 的接入计划已取消，相关接口现已移除。

已补齐创作模式、减少动画、左侧栏折叠、画布按项目的缩放与平移、鼠标/抓手工具、OM 工具和项目选择、素材/技能筛选、搜索条件、已选技能以及支付方式单选的本地记忆。支付仅记忆选项，不执行付款。

模型及生成参数继续使用原有分模式存储；画布 Agent、主题、节点参数和连接继续使用各自存储。失效的模型/选项不强行恢复，仍由当前目录约束。

自动下载开关已启用并保存。首页与节点共用的生成接口在结果就绪时触发下载，异步任务查询得到素材后同样触发。桌面自动下载保存到系统下载目录下的 Zora，文件名含随机标识避免覆盖；重复查询同一结果在当前运行中去重。没有可下载结果不触发，获取失败不会打开外部网页。

设置页第三方 API 信息区块已移除，密钥配置机制未改变。

验证：verify-preferences.mjs 检查开关、创作模式、侧栏、缩放与工具跨刷新恢复；verify-auto-download.mjs 用本地模拟生成结果实际落盘 3 个测试文件，Electron 均报告 completed。文件只写入 outputs/auto-download-verification/Zora，无付费调用。模拟 MP4 仅用于下载字节验证，不代表生成了可播放的视频。

资源缓存戳 studio131。自动下载的目录处理改动在 Electron 主进程，需完全退出桌面程序后重新打开。

最终原有桌面回归 31/31 通过，无页面错误。测试初始化显式清空测试搜索条件，避免新增的搜索记忆影响独立场景；结果位于 outputs/preferences-regression-final/desktop-results.json。
