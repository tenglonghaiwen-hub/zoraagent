# Zora 用户手册

## 欢迎使用 Zora

Zora 是一款本地创作助手，集成了对话、图像/视频生成、文件处理和桌面自动化功能。

---

## 快速开始

### 1. 首次启动

**方法一：桌面客户端（推荐）**
```powershell
.\start-zora-desktop.cmd
```

**方法二：仅后端服务**
```powershell
.\start-zora.cmd
```
然后访问 http://127.0.0.1:4317

### 2. 配置 API Key

首次使用需要配置模型 API Key：

1. 打开设置页面（右上角齿轮图标）
2. 在"模型配置"中填入：
   - **主 Agent API Key**: 用于对话和文字任务
   - **多元生成 API Key**: 用于图像/视频生成
3. 保存配置并重启服务

**Windows DPAPI 加密存储（推荐）：**
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/set-minimax-key.ps1
```

### 3. 开始对话

在输入框中输入需求，例如：
- "帮我生成一张日落的图片"
- "创建一个包含销售数据的 Excel 文件"
- "搜索 Python 异步编程教程"

## 核心功能

### 💬 对话助手

**支持的任务类型：**
- 文字对话和问答
- 方案设计和建议
- 代码编写和调试
- 文档编写

**多轮对话：**
- 会话自动保存，支持上下文连续对话
- 点击左侧历史记录恢复之前的会话

### 🖼️ 图像生成

**支持的模型：**
- GPT Image 2（默认）
- 其他多元接口模型

**使用方式：**
1. 直接描述需求："生成一张猫的图片"
2. 指定参数："生成 16:9 比例的风景图"
3. 参考图片：点击 `@` 上传参考素材

**可调参数：**
- 比例：1:1, 16:9, 9:16 等
- 分辨率：根据模型支持
- 数量：一次生成多张（最多 4 张）

### 🎬 视频生成

**支持的模型：**
- MiniMax H3（默认）
- 其他视频生成模型

**生成模式：**
- **文生视频 (t2v)**: 纯文字描述
- **图生视频 (i2v)**: 上传参考图片
- **参考生成 (ref)**: 保持人物/风格一致性
- **首尾帧 (fl)**: 指定开始和结束画面

**参考素材：**
- 支持 1-9 张参考图片
- 图片需在对话中用 `@` 明确选择
- 素材保存在浏览器 IndexedDB 中

### 📁 文件处理

**支持的操作：**
- 读取工作区文件
- 创建 Excel、Word、PDF 等
- 执行脚本生成复杂文档

**文件交付流程：**
1. Agent 生成脚本
2. 提交工作流审批
3. 执行脚本生成文件
4. 验证文件完整性
5. 下载到本地（保存到 `下载/Zora/`）

**注意事项：**
- 只能操作工作区内文件（`workspace/`）
- 需要 Docker 支持容器执行
- 每步操作需要用户审批

### 🌐 网页浏览

**功能：**
- 搜索公开互联网信息
- 打开网页并提取文字和链接
- 读取当前页面内容

**使用示例：**
```
"搜索 Node.js 最新版本"
"打开 https://nodejs.org 查看文档"
"读取当前页面的下载链接"
```

**限制：**
- 仅用于浏览和提取信息
- 不支持表单提交、登录、支付等操作
- 不执行网页中的指令

### 🎥 剪映控制

**功能：**
- 查看剪映窗口
- 读取界面元素
- 执行有限的点击和输入操作

**工作流程：**
1. `listWindows` - 列出窗口
2. `readWindow` - 读取界面元素
3. 基于实际坐标执行操作

**限制：**
- 每次操作需要用户确认
- 不能猜测坐标或元素
- 完整导入-剪辑-导出流程尚未验收

### 🛠️ OpenMontage

**功能：**
- 视频合成和剪辑
- 字幕生成
- 语音合成 (TTS)
- 音频转写

**使用前提：**
- 需要启动 OpenMontage sidecar
- 需要 Python 运行环境
- 需要相关依赖已安装

**启动 sidecar：**
```
"启动 OpenMontage sidecar"
```

## 技能系统

### 什么是技能？

技能是预定义的任务模板，帮助 Agent 更好地完成特定类型的任务。

### 如何使用技能？

**自动匹配：**
- Agent 根据任务内容自动选择合适的技能

**手动选择：**
1. 点击输入框上方的"技能"按钮
2. 选择需要的技能
3. 发送消息时技能会被应用

**可用技能：**
- 视频生成技能
- 人物生成技能
- 其他导入的 Codex 技能
- OpenMontage Layer2 技能

## 任务管理

### 查看任务

点击右侧"任务"面板查看：
- 生成任务状态
- 工作流执行记录
- OpenMontage 任务

### 任务状态

| 状态 | 说明 |
|------|------|
| `planned` | 已规划，未提交 |
| `running` | 生成中 |
| `completed` | 已完成 |
| `failed` | 失败 |
| `unknown` | 状态未知（需查询原任务）|

### 任务恢复

服务重启后：
- 历史任务记录会恢复
- 中断任务标记为 `unknown`
- 不会自动重提交任务（避免重复计费）

## 审批系统

### 为什么需要审批？

某些高风险操作需要用户明确授权：
- 文件读写
- 命令执行
- 桌面操作
- 批量删除

### 审批流程

1. Agent 提出操作请求
2. 对话中显示审批卡片
3. 用户点击"批准"或"拒绝"
4. 操作执行或取消

### 审批模式

在设置中可选择审批策略：
- **严格模式**: 所有操作需审批
- **标准模式**: 高风险操作需审批（推荐）
- **宽松模式**: 仅危险操作需审批

## 工作区

### 工作区位置

默认工作区：`workspace/`

可通过环境变量修改：
```powershell
$env:ZORA_WORKSPACE_ROOT = "D:\my-workspace"
```

### 工作区规则

- Agent 只能访问工作区内文件
- 不能访问整台电脑的文件系统
- 路径使用相对路径（如 `data.txt`，不是 `C:\data.txt`）

### 文件下载

生成的文件会保存到：
- **桌面版**: `用户下载目录/Zora/`
- **浏览器版**: 浏览器默认下载位置

## 常见问题

### Q: 为什么 Agent 没有响应？

**可能原因：**
1. API Key 未配置或无效
2. 网络连接问题
3. 服务未启动

**解决方法：**
1. 检查设置中的 API Key
2. 查看控制台错误信息
3. 重启服务

### Q: 生成任务一直是 "running" 状态？

**可能原因：**
1. 上游生成服务较慢（正常现象）
2. 任务在队列中等待
3. 网络超时

**解决方法：**
- 等待 2-5 分钟后刷新
- 查看任务详情中的错误信息
- 如超过 10 分钟，可重新提交

### Q: 无法访问某个文件？

**可能原因：**
- 文件不在工作区内
- 路径格式不正确
- 缺少权限

**解决方法：**
- 确保文件在 `workspace/` 目录下
- 使用相对路径（如 `data/file.txt`）
- 检查文件权限

### Q: Docker 不可用？

**检查方法：**
```powershell
docker ps
```

**解决方法：**
- 启动 Docker Desktop
- 检查 Docker 引擎是否运行
- 确认镜像已下载（`node:24-bookworm-slim`）

### Q: 素材上传后找不到？

**注意事项：**
- 素材保存在浏览器 IndexedDB
- 清空浏览器数据会丢失素材
- 不同浏览器不共享素材
- 发送时需用 `@` 明确选择素材

### Q: 如何导出会话记录？

**方法：**
1. 会话记录保存在 `data/chat-sessions/`
2. 可直接备份该目录
3. 或使用导出功能（如果前端已实现）

## 故障排查

### 1. 服务启动失败

**检查清单：**
- [ ] Node.js 版本 >= 22
- [ ] 端口 4317 未被占用
- [ ] Codex 可执行文件存在
- [ ] 环境配置正确

**日志位置：**
- 控制台输出
- `outputs/` 目录（如有）

### 2. Codex 内核未启动

**检查：**
```powershell
Invoke-RestMethod http://127.0.0.1:4317/api/agent/status | ConvertTo-Json -Depth 5
```

**期望输出：**
```json
{
  "kernel": {
    "available": true
  }
}
```

### 3. 生成失败

**常见错误：**
- 余额不足：充值 API 账户
- 参数不合法：使用预览功能检查
- 网络超时：重试或检查网络
