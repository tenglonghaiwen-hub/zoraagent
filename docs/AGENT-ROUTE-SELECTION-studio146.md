# Agent 显式操作与路由选择

> 维护说明（2026-09-15）：当前能力、入口与限制见 [当前实现状态](CURRENT-STATUS.md)。本文中的版本验收数字、当时状态和后续计划保留为历史记录；涉及 RunningHub 的接入计划已取消，相关接口现已移除。

2026-09-14。原则：用户明确要求优先，其次为仍有效的上下文，再由 Agent 判断，最后使用默认值。主 Agent 分析指令，媒体子 Agent 选择目录中的 operation、apiRoute 和参数；后端只验证兼容性、打包与执行。

- 工具 preview_task、submit_generation 新增可选 operation（generate/reference）和 apiRoute。
- 模型 routes 目录仅描述现有适配器能力，不声称所有供应商渠道均验证成功。
- generate 不接受参考素材；reference 必须有素材；与 videoMode 冲突时拒绝。相对路径必须属于该模型和操作，不能传任意 URL。
- Qwen 的 reference 路径为 /v1/images/edits；其他模型沿用当前适配器路径及各自参考字段。
- 打包后再次校验真实路径，不静默替换选择。生成继续进入同一个持久任务系统。
- 显式字段保留至实际提交、任务收据和前端媒体记录，再次生成时继续传递。
- 旧请求不带新字段时保留原行为，不增加推导字段改变旧草稿指纹。

验证：56 项全量单元测试通过；包含 18 个媒体模型显式路径、Qwen 编辑路径、非法路径和操作冲突、工具到任务收据字段传递。没有真实付费调用，用户语义分析效果和供应商实际参考编辑效果未在本轮验证。

前端版本 studio146；需重启后端并刷新界面。后端不自动发现新路由或切换供应商内部渠道，不承诺任意自然语言要求都被程序化验证。
