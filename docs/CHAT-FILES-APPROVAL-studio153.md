# 对话审批与文件交付

> 维护说明（2026-09-15）：当前能力、入口与限制见 [当前实现状态](CURRENT-STATUS.md)。本文中的版本验收数字、当时状态和后续计划保留为历史记录；涉及 RunningHub 的接入计划已取消，相关接口现已移除。

对话页显示当前后台会话的本地审批卡；批准按钮直接提交本次具体操作，详情默认折叠，不再二次弹确认。任务页仅保留折叠执行记录。

新本地提案和工作流由服务端绑定 conversationId。执行串行化，比较执行前后文件列表；成功后新增或更新的成品附在记录 artifacts 中，显示于对应对话。该关联代表执行期间观察到的文件变化，不验证内容质量。

已有工作区文件通过对话的公共文件区与素材库访问；未关联旧审批在对话显式标为公共，不假装属于当前会话。原有图片视频素材区保持可用。

文件服务只开放允许的成品类型，拒绝脚本、隐藏项、密钥名、链接和越界路径。图片/视频/音频/PDF可内嵌，Office等文件可下载。此次未扩展任意本机目录、文件上传或桌面控制授权模式。

验证：105项测试通过，隔离Electron验证对话审批、跨会话隔离、公共旧审批和文件、任务页仅记录。后端已重启，HTTP已确认现有Excel在列表中；客户端缓存studio153，刷新后生效。
