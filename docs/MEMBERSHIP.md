# 会员套餐与预约降级

更新：2026-09-20。当前收银台仍是明确标注的演示流程，不代表已经接入真实支付、退款或订单核销。

## 规则

- 未开通或已到期：购买。
- 有效会员的同等级套餐：续费，从现有到期时间延长。
- 更高等级：购买，沿用现有购买后立即提高权益、延长有效期的行为；没有新增差价结算。
- 更低等级：预约降级。按北京时间，当前到期日期的次日 00:00 生效；不按下个自然月、不按点击后的一个月计算。比如到期于 3 月 31 日 13:30，降级从 4 月 1 日 00:00 开始。原权益保留到原到期时间。
- 新套餐的有效期从预约生效时间计算，赠送积分在生效时发放；预约时不降低现有并发或发放新积分。
- 终身会员不续费、不降级。已有待生效套餐时阻止再次购买，避免冲突安排；目前未提供取消预约或更改预约入口。

## 客户端

`apps/client/membership-state.js` 统一卡片、结算按钮和提示的行为。卡片采用圆角矩形和不同套餐强调色；选中状态同时使用勾选文字与边框，不仅靠颜色区分。支持方向键选择，日间、夜间、性能日间保持文字可读。

以 `/api/auth/me` 返回的 `membershipTier`、`pendingMembership`、`membershipScheduling` 为准。旧账号没有明确套餐记录时，按已有并发权益暂映射等级；无法由剩余有效天数准确反推购买套餐。后台未支持预约或缺少到期日期时，不允许提交降级。

确认操作带 `requestId`；同一收银台重试复用编号。网络或接口错误会原样显示，不再通过本地兜底模拟会员开通成功。

## 服务端及迁移

新增 `membership_state` 保存当前套餐、待生效套餐和修订号，`membership_orders` 保存幂等结果。D1 事务批次保证权益、赠送积分和订单记录的一致性，积分仍进入现有 `usage_logs` 账本。套餐天数、赠送积分和并发上限由服务端定义。

在已认证请求进入时检查预约，已到期安排在本次请求使用权益前原子落账；有效期始终按计划生效时间计算，不按首次重新登录的日期顺延。这是请求触发的切换，没有新增定时任务。

部署顺序（在 `apps/cloudflare-worker` 目录使用 Wrangler 4）：

```powershell
wrangler d1 execute zora-db --remote --file membership-state.sql --yes
wrangler deploy
```

`wrangler.toml` 的 `MEMBERSHIP_SCHEDULING="true"` 依赖迁移已执行。只新增两张表，不迁移或修改现有用户的会员值。部署版本：`cfd21147-b262-4e70-bf18-681e43f1006b`。
