## 已实施

- Agent submit_generation 和 call_api 的本地生成入口使用同一封装，为同轮相同参数生成稳定请求 ID，返回任务收据；禁止 Agent 直接绕过账本调用付费生成代理。
- /api/chat 返回独立于模型规划文字的 generationTasks；工具已提交但后续模型回复失败时，仍保留收据。未取得回执则明确标记未知，仅按原 ID 查询。
- 主会话、画布 Agent 将收据映射为媒体任务，按 ID 关联与去重，复用查询、持久化和结果归一化；查询无须重新读取原图。404 保留原 ID，不自动重提。
- 原图通过工具参数传递，文字历史不包含图片编码；缺失、过量或超限素材明确报错。当前限制为最多 6 项、每项 contentUrl 不超过 300 万字符。
- 画布 Agent 重绘保留阅读位置。前端缓存统一为 studio144。
