# 本机 Agent 执行首版验收

> 维护说明（2026-09-15）：当前能力、入口与限制见 [当前实现状态](CURRENT-STATUS.md)。本文中的版本验收数字、当时状态和后续计划保留为历史记录；涉及 RunningHub 的接入计划已取消，相关接口现已移除。

本轮接入独立本机工作区文件读写、容器命令、用户审批、持久聊天记录和固定依赖工作流。默认工作区为 `D:\zora\workspace`，由 `ZORA_WORKSPACE_ROOT` 配置；不会自动读取其他本机目录。

## 已实现

- 主 Agent 可查询运行状态、提议具体操作、创建最多 20 步依赖任务。
- 任务页显示操作内容，用户批准后才执行。Agent 工具白名单不允许调用审批接口。
- 容器关闭网络、移除 capabilities、限制内存/CPU/进程数，根文件系统只读；工作区可写。无宿主终端回退，不自动拉取镜像。
- 审批在执行前持久消费；服务中断后不重放结果未知的命令。依赖成功后每秒调度后续待审批步骤，拒绝或失败会阻止依赖步骤。
- 聊天会话由服务端落盘，重启读取；损坏主文件可读取有效备份。未实现中断模型回合续跑或 HTTP 重试幂等。

## 验证与限制

单元测试、审批界面模拟测试与语法检查通过。未调用真实付费生成服务。

本机没有 Docker 命令，真实容器读写与终端执行受阻。需安装并启动 Docker Desktop，准备 Linux 容器，并预先拉取 `node:24-bookworm-slim`（或通过 `ZORA_SANDBOX_IMAGE` 配置已安装镜像）后才能实测。此时批准按钮保持禁用。

当前是固定依赖的本地操作工作流；不是任意媒体任务自动串联、模型自动持续唤醒或完整 Codex 工具生态。需要在独立工作区准备待处理文件；并未授予整台电脑访问权限。终端操作可修改工作区内容，审批前应查看具体命令。

历史 HANDOFF 文档保留原样。客户端缓存版本为 studio149。
