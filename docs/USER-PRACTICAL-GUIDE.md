# 造境 Zora 用户功能实操方案与案例

编写日期：2026-09-21。面向包含 OpenMontage 和语音运行库的 Windows 测试安装包。

本方案可作为新手教程、演示录屏脚本和客服操作手册。以下案例是可照做的教学设计，不是已完成的客户案例；本次没有提交付费生成。模型、可选参数和积分报价以当前客户端实际返回为准。

## 1. 教学目标与安排

让用户学会：上传并引用素材、把需求说清楚、先核对计划再生成、查看真实进度、修改局部结果、下载交付文件。

| 课程 | 建议讲解时长 | 用户完成的操作 |
| --- | --- | --- |
| 首次使用 | 5 分钟 | 启动、检查服务、认识对话/任务/素材库/画布/设置 |
| 第一套商品图片 | 10 分钟 | 引用原图、规划四张独立页面、确认生成、查看每张状态 |
| 商品短视频 | 10 分钟 | 指定参考角色、核对支持参数、生成并查询结果 |
| 本地剪辑与字幕 | 10 分钟 | 检查本地能力、裁剪、转录校对、导出 |
| 修改与异常处理 | 5 分钟 | 换参考图、局部调整、查询原任务、防止重复提交 |

以上是教学安排，不包含模型下载和云端生成等待时间。建议以商品内容创作者为首批教学对象；先做通商品图和已有视频剪辑，再演示组合流程。

## 2. 开始前准备

1. 安装并打开最新版桌面客户端；按界面完成账户使用流程，确认对话和模型目录可用。不要让普通用户配置后台路由。
2. 在“设置 → 本地媒体能力”检查所需能力。勾选表示允许使用，不等于所有依赖、模型与音色已准备好。
3. 最新包已包含 FFmpeg、基础转录运行库和 Piper 程序。转录模型首次使用可能联网下载；Piper 仍需已有 `.onnx` 音色和同名 `.onnx.json` 配置，并在设置中选择对应路径。先检查音色许可。
4. 准备自己的商品图片、短视频和文案。建议首次演示采用一张清晰商品图和一个小于 64 MiB 的短视频，避开大文件导入限制。
5. 涉及云端生成先查看模型、参数、数量和报价。不要宣传本地处理“完全免费”：本地剪辑不产生媒体生成 API 费用，但 Agent 分析、云端生成等仍可能计费。

## 3. 用户如何选择入口

| 入口 | 适合做什么 | 使用要点 |
| --- | --- | --- |
| Agent 对话 | 描述需求、多轮修改、组合任务 | 推荐新手从这里开始；无需知道工具名或 API 路由 |
| 素材库 | 查看本地上传与生成结果 | 原素材保存在本机；同一会话可恢复，不代表自动跨电脑同步 |
| 任务 | 查看草稿与执行记录 | 有任务编号只代表已提交，完成需核对真实输出 |
| 画布 | 整理生成结果和参考素材 | 从结果卡片“全部插入画板”开始；画布参考选择与主对话独立 |
| 设置 | 本地媒体能力、素材来源、显示和工具设置 | 未就绪时先处理缺项，不反复发送相同生成请求 |
| 技能中心 | 了解现有技能 | 一般任务由 Agent 按指令选能力，无需用户每次手动选技能 |

对话的“思考与执行”用于查看工具进度与错误；手动展开后可继续阅读，向上查看历史时可用“回到最新”返回底部。

## 4. 通用指令写法

按“目标 + 素材角色 + 每项内容 + 风格 + 输出规格 + 执行边界”描述需求。

> 我要做【用途】。使用 @图片1 作为【产品参考】，@视频1 作为【动作或节奏参考】。需要【数量与逐项内容】。统一【风格约束】，输出【比例、清晰度、时长或格式】。先检查素材和当前可用能力，给出方案与报价，暂不生成；缺少条件请明确告诉我。

上传后用输入框的素材引用功能选中实际素材；示例编号要对应当前会话。不要只输入一个本机无法读取的文件名。

主对话可沿用最近一次已发送参考；本轮明确引用新素材会替换沿用列表。如需同时保留旧图，请明确引用两张并写清各自用途。新会话、另一台电脑或实际文件丢失时，不能假定旧素材仍可读。

## 5. 案例一：服装四张独立详情图

**目标：** 同一商品做首页、细节、版型和面料四张图，风格统一，每张只承担一个页面任务。

**准备：** 一张清晰原商品图；最好另有真实细节图。参考看不到的背面、材质和结构不应被当成已知事实。

**操作：** 新建对话 → 上传并引用商品图 → 发送以下规划指令。

> 以 @图片1 为唯一商品参考，规划一套四张独立的电商详情图：1 商品首页；2 领口细节；3 版型展示；4 面料细节。共同风格为米白背景、柔和光线、克制中文排版，保持商品颜色、轮廓和装饰一致。每张 9:16，优先 2K，不支持时先告知。每张只生成对应内容，禁止四宫格和整套拼图。图片中看不清的细节先向我确认。请先列共同风格、四张各自提示词和总报价，不要提交生成。

核对逐张描述、参考和报价后，再发送“确认按这份方案生成这四张独立图片”。等待结果卡片逐张完成，可展开详情检查各张提示词与任务编号。

**验收：** 四个独立文件；内容顺序正确；没有重复拼图；商品关键细节一致；文字可读。共同风格约束不能保证像素级一致，真实画面需要人工检查。

**继续修改：**

> 只调整第 2 张，把领口占比提高，保留其余三张。先给修改后的单张提示词和报价，不要重新提交整套。

当前整套规划支持 2–12 个独立页面，每张独立提交。遇到失败或未知状态可能停止后续页面；请先查状态，不要把空位当成已经生成。

## 6. 案例二：商品图变成短视频

**目标：** 用已确认的商品图制作一个简洁展示镜头。

**准备：** 一张确认可用的商品图；如要参考动作，另外准备自己有权使用的短视频。

> 使用 @图片1 作为商品外观参考，制作约 5 秒、9:16 的展示视频。镜头缓慢靠近商品，背景保持简洁，商品结构、颜色和装饰不变，不增加人物和文字。请根据当前开放模型选择支持的生成方式；检查时长、分辨率和参考要求，先说明方案与报价，暂不提交。

如使用参考视频，补充：“@视频1 只参考镜头运动和节奏，商品外观仍以 @图片1 为准。”是否支持此组合取决于所选模型，不保证所有模型支持视频参考。

**操作与验收：** 确认后提交 → 在原结果卡片查询 → 播放检查主体变形、闪烁、时长和比例 → 下载。继续调整已生成视频时说清“基于这个已完成视频修改”，Agent 仅在当前开放能力支持时选择再生成；不把任何“修改”都当成已支持的视频编辑。

## 7. 案例三：已有口播剪成可发布片段

**目标：** 先完成可验证的本地裁剪，再做字幕。

**准备：** 一段声音清楚的口播；设置中启用剪辑和转录。第一次使用先等待转录模型准备完成。

> 处理 @视频1：先检查时长、音轨和本地能力，裁出第 2 秒到第 17 秒，保留原声，不添加新画面，输出新文件，不覆盖原视频。完成后检查输出能否播放，并给出保存位置。若视频不足 17 秒，先告诉我。

拿到裁剪结果后：

> 为刚才的片段转录中文字幕，先交付带时间戳的文本让我校对，暂不烧录字幕。人名、商品名和数字不确定时标出来。

校对后：

> 使用这份校对后的字幕，输出底部居中、白字深色描边的字幕视频。如果当前字幕工具缺少依赖，明确报告缺项，先交付可用字幕文件。

**验收：** 原文件未改动；裁剪约 15 秒；音画同步；字幕时间和专有名词正确；字幕未遮挡主体。基础转录已实测，但不保证所有字幕样式管线就绪，也不承诺说话人分离可用。

## 8. 案例四：商品介绍本地配音

**目标：** 为一段已校对文案生成配音，之后再与视频合成。

**准备：** 在设置中填写有效的中文 Piper 音色路径，确保配置文件齐全，能力检查通过。

> 使用已配置的本地中文音色，为下面文案生成 WAV 配音，先检查音色是否可用，不调用云端语音服务，不自动添加背景音乐。文案：“一件适合日常搭配的连衣裙，简洁线条，轻松穿出自己的风格。”输出后检查音频时长并提供文件。

**验收：** 试听发音、停顿、音量；品牌名如有误读先改文案。该能力使用选定音色，不是声音克隆。缺少音色时先完成设置，不重复生成。

继续合成时引用实际视频和音频，要求先比较时长再提出裁剪或留白方案；不要未经确认改变文案速度或画面内容。

## 9. 案例五：从商品到完整宣传片

**目标：** 展示软件的组合价值；建议放在进阶教程，而非首次启动演示。

> 我要制作一条约 15 秒的竖屏商品宣传片。@图片1 是唯一商品参考。请先规划三个镜头、屏幕文案和配音，列出已有素材、需要新生成的素材、本地处理步骤及各项报价。新图片和视频使用当前已配置的生成服务；剪辑和配音优先使用已就绪的本地能力。先给计划，不生成、不下载额外模型，待我确认后分阶段执行。

分阶段推进：① 确认脚本与参考；② 确认云端生成报价并取得实际输出；③ 确认配音；④ 将已完成媒体导入本地项目；⑤ 剪辑、字幕与导出；⑥ 播放验收。

**验收：** 每个镜头都有真实文件，成片时长接近目标，参考商品一致，字幕和配音相符。Agent 创建管线计划不代表已经出片；当前不是所有管线均已完成端到端实测，也没有独立的逐步自动恢复引擎。

## 10. 可选案例：检索公共素材

在设置中启用素材检索并选择来源。Pexels/Unsplash 需要用户自己申请并填写密钥，换电脑要重新配置；不要把密钥发给 Agent。其他来源不要求这里填写密钥，也不等于素材都可任意商用。

> 寻找三段适合自然风景短片的素材，优先使用我已启用的来源。先给候选的预览链接、作者、来源和许可说明，不下载、不生成。用途是商业宣传，许可不明确的标出来，不要认定可以商用。

此案例依赖网络与第三方服务。本版本未使用真实用户密钥完成线上检索验收，录制公开教程前需实际验证，不把测试密钥保存成功说成服务可用。

## 11. 用户遇到问题时怎么做

| 现象 | 建议操作 |
| --- | --- |
| 已扣费但没有图片或视频 | 刷新原任务结果，记录任务编号、模型、时间和错误；要求查询原任务，暂不再次生成 |
| 显示“结果待确认”或状态未知 | 不等于失败或免费重试；先核对回执，无法恢复时提供信息给客服 |
| 显示缺少原素材 | 检查是否同一会话和同一电脑；本机确实没有保存文件时再添加，不能仅凭文件名恢复 |
| 更换商品后仍描述旧商品 | 明确引用新图，要求重新分析主体并重写共同风格中的商品描述，保留适用的版式 |
| 点击停止后上游还在生成 | 停止 Agent 不等于取消已经提交的上游媒体任务；继续查询该任务，不反复提交 |
| 删除任务记录 | 只删除可见记录不代表取消生成；先保存需要的结果和任务信息 |
| 本地配音/转录不可用 | 区分程序缺失、模型未准备、音色路径错误和开关关闭；按实际状态处理 |
| 下载没有完成 | 以下载完成提示和实际文件为准；桌面默认下载到 Downloads/Zora，网页模式行为可能不同 |

## 12. 发布教程的交付清单

建议制作五条短教程：首次使用、四张商品详情图、参考图生视频、本地裁剪与字幕、查询失败与避免重复生成。每条固定展示“输入素材 → 原始指令 → 参数/报价 → 真实执行 → 输出验收 → 一次修改”。

每个案例包包含：获得授权的原始素材、可复制指令、共同风格与分项计划、实际输出、模型/参数/日期、实际积分记录、失败处理说明。公开截图去掉账号、密钥、私人路径等信息。

演示结果区分：教学方案、真实生成结果、界面示意。没有真实产物的案例不写“成功案例”，不承诺固定完成时间、零失败或风格完全一致。

上线前优先实测：一套四张不同内容的商品图、一个参考图视频、小视频裁剪与中文字幕、已配置音色配音、重启后原会话素材恢复与原任务查询。在另一台干净 Windows 电脑重复关键流程后，再声明新电脑可开箱使用。
