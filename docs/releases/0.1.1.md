# Zora 0.1.1

本版本改善 Windows 新电脑首次运行，加入后续稳定版本更新入口。

- 本地媒体服务不可用时仍可进入主界面，并查看错误与重试。
- 本地端口冲突自动恢复，保留原页面地址、会话与本机素材存储。
- 补齐 PPTX 校验工具和 PPTX、Excel、Word、PDF 生成运行库。
- 修正无 Docker 时脚本未执行却显示完成的问题。
- 增加转录模型检查、下载进度与重试，支持选择已有本地配音音色。
- 附带微软官方 x64 C++ 运行库安装程序，可在设置中主动安装或修复。
- 新增代理设置及稳定版检查、下载、确认安装流程。

升级前请保存工作并结束本地任务。0.1.0 没有更新模块，需要手动安装本版本；用户素材与账号数据不会由安装包跨电脑迁移。转录模型、配音音色和第三方素材密钥仍需按界面准备。

测试：348 项回归；Electron 端口冲突与媒体服务失效模拟；文档产物结构/回读；Tiny 模型实际下载与 CPU 加载；设置交互和代理链路。
