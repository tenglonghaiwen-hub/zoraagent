# 视频画面理解接入

> 维护说明（2026-09-15）：当前能力、入口与限制见 [当前实现状态](CURRENT-STATUS.md)。本文中的版本验收数字、当时状态和后续计划保留为历史记录；涉及 RunningHub 的接入计划已取消，相关接口现已移除。

后端 chat-service 现在解析已上传视频，向主 Agent 及媒体子 Agent 提供带时间戳的 JPEG 视觉输入。图片与视频帧共用 6 个视觉槽位；每视频最多 3 帧。原视频不压缩、不改写，生成工具仍收到原始素材。

支持原始 data URL 的 MP4/MOV/WebM/AVI，最大 30 MiB。拒绝网络 URL、播放列表、伪装格式和无法解码的文件；失败不调用模型，并恢复聊天发送锁。

依赖本机 ffmpeg/ffprobe，本机已在 D:/ffmpeg/bin 验证。稀疏静态帧不等于完整动作观察；音频未转写，提示词明确禁止凭空推断声音和未采样内容。

验证：76 项测试通过，其中包含真实 FFmpeg 短视频抽帧、原文件保持不变、帧预算、输入拒绝、聊天视觉参数传递和失败释放锁。未调用付费模型验证实际回复。

临时素材保留在系统 Temp 下的 zora-video-frames-* 目录。本轮未删除文件；长期运行前需补充可配置保留策略。后端需要重启才能加载新模块。历史会话不会自动重新分析，需重新附上视频发送。
