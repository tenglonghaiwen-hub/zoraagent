# Zora 独立浏览器

> 维护说明（2026-09-15）：当前能力、入口与限制见 [当前实现状态](CURRENT-STATUS.md)。本文中的版本验收数字、当时状态和后续计划保留为历史记录；涉及 RunningHub 的接入计划已取消，相关接口现已移除。

主 Agent 新增 `browser_search`、`browser_open`、`browser_read`。桌面端提供独立浏览器窗口，使用独立临时会话，不共享日常 Chrome/Edge 资料或登录状态。

搜索使用 Bing；打开来源后返回当前页面标题、网址、可见正文和链接。动态加载页面可再次读取。不是通用鼠标键盘控制，暂不支持 Agent 填表、点击按钮或提交操作。登录、验证码或网站拒绝访问时如实说明，不绕过。

网页文本是不可信资料，不是用户授权。Agent 应核实来源并提供实际 URL，不能将搜索摘要当作完整原文。

桌面桥仅监听本机随机端口，以随机令牌验证，拒绝网页 Origin 请求。桌面进程以外的后端通过 data/browser-bridge.json 定位本机桥；描述文件不得发送给模型或网页。浏览器关闭 Node 和 preload 能力，并阻止本地网络和文件地址、权限请求、下载与新弹窗。

需重启 Zora 桌面端及后端加载功能。关闭桌面端后，工具会报告浏览器未就绪。此能力不依赖 Docker，也不代表取得整台电脑控制权。

验证：93 项单元测试通过；隔离 Electron 实际打开 example.com 并读取正文成功，窗口重开、隔离配置、认证与私网地址拒绝检查通过。证据位于 outputs/browser-bridge-20260914-175751/smoke-result.json。后端已重启并确认包含 browser_search 工具；用户当前桌面窗口未中断，需退出重开加载桥接模块。
