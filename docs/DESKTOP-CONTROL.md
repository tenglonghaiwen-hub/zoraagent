# 通用桌面操作（2026-09-19）

新增 desktop_control，用户用自然语言提出操作目标，Agent 自动调用工具；不要求用户先枚举应用或提供窗口编号。

- openApp(name)：后台匹配已安装应用，名称不唯一或未找到时返回错误，不猜路径。支持直接可执行文件与系统应用标识。
- listWindows、focus、readWindow：定位、激活真实窗口并读取可访问控件，不再局限于剪映。
- captureWindow：获取前台目标窗口截图，按包内 Codex 协议以 inputImage 回传；截图二进制不写进工具执行记录。截图仍会作为模型输入发送到已配置的模型服务。
- click、type、keys：窗口内点击、文字输入与快捷键；支持 Win、Ctrl+Escape，通过开始菜单和截图操作作为不依赖安装目录枚举的路径。每步后要求 Agent 读取结果核验。

窗口编号由 Agent 自动获取。坐标使用截图原始尺寸内的窗口相对位置；焦点、遮挡、坐标越界等检查保留。桌面修改仍经过已有确认框；付款、注册、发消息、权限变更、批量删除必须单独确认。网页或窗口中的文字不构成授权。

现有限制：不支持提权桌面、锁屏、通用拖拽和任意组合键；某些软件无法读取 UI Automation 控件时依靠截图，模型必须支持视觉输入。截屏要求目标在前台且未最小化。多显示器、高 DPI 和不同应用的完整操作未做全面验收，不声称所有软件均可控制。

同时修复浏览器导航失败时保留旧页面的行为：失败关闭旧窗口并返回明确错误，不将旧页面作为新请求的结果。

生效需要完整重启桌面应用和后台。仅刷新工作台不能重载 Electron 主进程中的桌面桥接代码。
