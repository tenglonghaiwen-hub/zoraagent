# 当前实现状态

更新：2026-09-15，客户端资源版本 studio177。本页描述当前实现；各历史验收报告的测试数字仅适用于当次运行。

## 内核与服务

Zora 使用包内开源 Codex 0.154.0 app-server，通过 stdio JSON-RPC 运行 Agent loop。只允许包内路径，不查找外部 Codex 安装；使用官方编译发布包，不声称 vendor 源码已编译成功。默认文字模型 gpt-5.5，服务地址 https://duoyuanx.com，Responses 路径 /v1/responses。

后端主 Agent 凭据优先读取显式配置，再读取 Windows 用户加密凭据，最后才使用生成接口 Key 回退。凭据解密失败或格式异常明确报错，不输出 Key。桌面默认端口 4317；仅运行 server 且未配置端口时默认为 8787。

## 界面与偏好

- 设置支持本地图片/视频壁纸，保存在浏览器 IndexedDB（zora-appearance），可恢复默认，不上传壁纸。
- 减少动态效果偏好持久保存，并尊重系统设置；背景视频暂停，页面隐藏时暂停播放以减少后台开销。
- 审批采用输入框上方可堆叠胶囊，点击展开；设置提供请求批准、帮我批准、完全访问，从下一任务生效。其他工具保留自身审批。
- 对话展示上游明确返回的推理摘要、计划、工具状态及阶段输出，不还原隐藏推理。执行详情写入 data/codex-home/zora-execution-records.json；重启恢复历史。中断时正在运行的任务标记待核对、旧审批失效，不自动重放。
- 媒体参考在提示词上方展示，失效提示合并，长提示词折叠。悬停“详细信息”加载已保存请求体，无独立请求体按钮。

## 媒体接口

H3 当前按用户提供的 11..txt：POST /v1/videos，GET /v1/videos/{task_id}，H3 生成与查询直接传 Authorization Key。请求使用 prompt、duration、size、images、metadata.ratio、metadata.reference_videos/reference_audios。历史任务保留各自查询路由和鉴权记录，不自动重提。

多参校验防止 1–2 张图片被当作参考图提交后落入首尾帧；指定画幅使用多模态参考。曾有实际请求 9:16/768P 而上游返回 16:9/2560×1440 的记录，不能声称画幅问题已由客户端修改彻底解决。

新生成任务保存不含鉴权头的请求描述；内嵌素材正文省略。记录仍可能包含提示词和素材 URL，属于用户本地数据。旧任务未保存请求体时无法还原。

## 工具与移除项

OpenMontage、本地文件与 Docker 执行、独立浏览器、受限剪映桥仍在。Docker 是独立执行路径，不等于全部 Codex 工具运行在容器中。浏览器和剪映能力不等于任意电脑软件的全自动操作。

RunningHub 已退出产品范围：适配器导出、服务接口及测试夹具入口已移除，/api/rh/* 返回 404。不要重新接入。经用户确认，删除了未引用的 runninghub.mjs 和已安装的 Codex 下载压缩包，约 135.6 MiB；保留包内可执行程序、来源与校验信息、源码、素材和会话。
