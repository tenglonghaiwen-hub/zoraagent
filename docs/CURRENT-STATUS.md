# 当前实现状态

更新：2026-09-16，客户端资源版本 studio182。本页描述当前实现；各历史验收报告的测试数字仅适用于当次运行。

## 内核与服务

Zora 使用包内开源 Codex 0.154.0 app-server，通过 stdio JSON-RPC 运行 Agent loop。只允许包内路径，不查找外部 Codex 安装；使用官方编译发布包，不声称 vendor 源码已编译成功。默认文字模型 gpt-5.5，服务地址 https://duoyuanx.com，Responses 路径 /v1/responses。

后端主 Agent 凭据优先读取显式配置，再读取 Windows 用户加密凭据，最后才使用生成接口 Key 回退。凭据解密失败或格式异常明确报错，不输出 Key。桌面默认端口 4317；仅运行 server 且未配置端口时默认为 8787。

## 界面与偏好

- 设置支持本地图片/视频壁纸，保存在浏览器 IndexedDB（zora-appearance），可恢复默认，不上传壁纸。
- 减少动态效果偏好持久保存，并尊重系统设置；背景视频暂停，页面隐藏时暂停播放以减少后台开销。
- 审批采用输入框上方可堆叠胶囊，点击展开；设置提供请求批准、帮我批准、完全访问，从下一任务生效。其他工具保留自身审批。
- 对话展示上游明确返回的推理摘要、计划、工具状态及阶段输出，不还原隐藏推理。执行详情写入 data/codex-home/zora-execution-records.json；重启恢复历史。中断时正在运行的任务标记待核对、旧审批失效，不自动重放。
- 媒体参考在提示词上方展示，失效提示合并，长提示词折叠。悬停“详细信息”加载已保存请求体，无独立请求体按钮。

## 媒体接口

H3 从 2026-09-16 改用 MiniMax 官方直连：https://api.minimax.cn，POST /v2/video_generation，GET /v2/query/video_generation/{task_id}，Bearer MINIMAX_API_KEY（独立于中转密钥）。content 明确标注 first_frame/last_frame 或 reference_image/reference_video/reference_audio；duration、resolution、ratio 位于顶层。参考模式支持1–9张图，首尾帧仅 adaptive。

旧 H3 提交实现保留为注释；历史回执仍按保存的旧查询通道读取。缺少官方密钥明确阻止提交，不回退。素材使用公网URL或内嵌数据；请求总大小不得超过64MB。官方单文件尺寸、时长和大小限制仍适用。

新生成任务保存不含鉴权头的请求描述；内嵌素材正文省略。记录仍可能包含提示词和素材 URL，属于用户本地数据。旧任务未保存请求体时无法还原。

## 工具与移除项

OpenMontage、本地文件与 Docker 执行、独立浏览器、受限剪映桥仍在。Docker 是独立执行路径，不等于全部 Codex 工具运行在容器中。浏览器和剪映能力不等于任意电脑软件的全自动操作。

RunningHub 已退出产品范围：服务接口已移除，/api/rh/* 返回 404，工具管理界面过滤 rh_ 项。packages/agent/tools.mjs 仍保留旧 rh_ 工具定义与分支，不能称代码已完全清除。不要重新接入。经用户确认，删除了未引用的 runninghub.mjs 和已安装的 Codex 下载压缩包，约 135.6 MiB；保留包内可执行程序、来源与校验信息、源码、素材和会话。

## 技能选择与工具管理

本轮任务按关键词匹配已安装的视频、动作迁移与人物技能，显式技能优先，支持“不用技能”。选择的技能与原因显示在“思考与执行”中，并传递给媒体子任务。这是规则选择，不代表任意新技能都能自动匹配。

设置中的“工具管理”提供 Zora 扩展工具目录、搜索和持久化启停；调用时重新检查禁用状态。原生 Codex 工具继续通过审批设置控制，不包含任意 MCP 服务安装管理。

验收：全量 133 项通过；新增工具持久化和目录校验通过。真实包内 Codex + 本地模拟上游完成工具调用、线程恢复、历史记录恢复。无付费生成。

执行错误会记录时间、原因及上游是否重试，在“思考与执行”展示并持久保存（最多50条，密钥脱敏）。停止按钮位于折叠区域外，停止当前会话的主线程和媒体子线程；停止请求尚待确认时不宣称已停止。已提交上游的媒体任务不属于 Agent 中止范围。

素材库按相同结果URL合并展示，新结果入库避免重复插入，不删除原文件。会话启动后从 IndexedDB 恢复原素材；媒体发送前等待素材保存。已丢失且未保存到本机的历史原素材无法自动找回。
