# 画布节点工作流 — studio124

> 维护说明（2026-09-15）：当前能力、入口与限制见 [当前实现状态](CURRENT-STATUS.md)。本文中的版本验收数字、当时状态和后续计划保留为历史记录；涉及 RunningHub 的接入计划已取消，相关接口现已移除。

## 已实现
- 空白处双击选择节点。文字节点输入与文字模型调用；图片、视频节点复用首页模型目录和 submitMediaGeneration 接口，不再使用固定模型/参数的独立假表单。
- 右侧 + 选输出，目标左侧 + 连接；支持多个输入，输入标签可断开；拒绝自身和循环连接。连线存储在节点 inputs，沿用原项目与 localStorage 键。
- 上游文本优先使用已生成回复，否则使用用户输入；素材优先使用生成结果，否则使用上传内容。目标指令与上游文字合并，素材通过 references 独立传递。失败、未完成、缺失的上游不能被当作成功结果。
- 各文字节点独立 conversationId，可新建文字会话。生成失败显示错误并恢复按钮；刷新中断显示失败提示。项目切换期间的返回结果保存到原项目，不写入当前项目。
- 异步媒体任务保存 taskId，提供“刷新生成结果”；没有素材或任务编号不显示成功。完成素材可继续连接下游。
- 模型、模式、比例、分辨率、时长、数量、并发读取同一服务端模型目录。首屏和节点均通过同一服务端校验。

## 素材适配范围与限制
- generateContent 图片路由支持内嵌 PNG/JPEG/WebP 参考图，使用 inlineData。协议依据：https://ai.google.dev/api/generate-content 。
- 按现有 catalog.referenceField 打包：input_reference 单图 multipart（Grok）、images 图片数组、video 单视频。真实供应商调用未执行，线上兼容性未验收。
- 未定义参考字段的模型明确拒绝参考生成；不支持的类型/数量不会静默丢弃。当前节点最多 6 个参考素材，上传仍限单文件 2 MB。Gemini 路由远程图片需下载后重新上传；任意音视频混合接入并非所有模型均支持。
- 采用逐节点手动执行：先准备/运行上游，再运行目标。尚无一键执行整张图或自动重新运行下游。资产库选择、特色工具执行、音频生成仍未接入。
- 当前复用模型目录与提交/查询逻辑，未迁移首页所有素材选择器和技能交互。

## studio125：鼠标拖拽连线
按住节点加号拖动，显示临时曲线；释放到另一节点的相反端口完成连接。支持从输出拖向输入，也支持从输入反向拖向输出；同一节点可多入、多出。空白释放、Esc、指针取消或窗口失焦取消临时线。连线端点采用端口实际中心坐标，节点拖动时更新，兼容画布缩放与平移。

验证：verify-node-workflow.mjs 已改用真实鼠标拖动并通过模拟生成链路；verify-drag-wires.mjs 覆盖多入多出、反向拖动、重复边、防环、Esc/空白取消、刷新、缩放后的连接。证据在 outputs/drag-wire-verification 与 outputs/drag-wire-interactions。
